# Contributing

Thanks for helping with UI SDK.

- **Bugs and ideas:** open an [issue](https://github.com/vercel-labs/ui/issues).
- **Security:** follow [SECURITY.md](SECURITY.md), never a public issue.
- **Code:** read [contributing/README.md](contributing/README.md) for the repo, how we work and the checks to run before a pull request. Ask in an issue before changing a public API, adding a component or adding a dependency.

By participating, you agree to our [Code of Conduct](CODE_OF_CONDUCT.md).
