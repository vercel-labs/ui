# @ui-sdk/solid

UI SDK for Solid. A library of behaviors to build your components.

```bash
npm install @ui-sdk/solid @ui-sdk/core
```

It needs Solid 2: `solid-js` and `@solidjs/web` 2.0.0-rc.14 or later.

[Read the docs](https://ui-sdk.dev/docs/solid)

The docs also ship in this package as Markdown, starting at `docs/llms.txt`, for your editor and your agent.
