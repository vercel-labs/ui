web.css

A small, flat design system for UI SDK components. Square by default, built from a handful of tokens, with no animation and shadows only on things that float. It styles parts through their data-slot and state attributes, so the same stylesheet works in React, Vue, Svelte, Solid and web components.

Use the bar above to switch color scheme and direction, or drag a token. Every example on this page updates.

Install

Without a bundler, add two tags. The stylesheet follows the same release as the loader.

<script type="module" src="https://ui-sdk.dev/web.js"></script>
<link rel="stylesheet" href="https://ui-sdk.dev/web.css" />

With a bundler, import it once from core, next to your own CSS.

import "@ui-sdk/core/web.css"

Everything sits in @layer ui-sdk, so any style you write without a layer wins. Components inherit your page's font. To use the system font, set font-family: var(--ui-font-sans) on body.

Principles

Flat Borders separate things. Shadows only appear on menus, lists, popovers and dialogs, which sit above the page.
Square Corners start at zero. One token rounds everything, and small parts scale from it.
Still Nothing animates. A state change is visible the moment it happens.
One height Every control is --ui-spacing × 8 tall, so inputs, selects and buttons line up on one row.
Yours to override A low cascade layer and plain custom properties. No classes to learn and nothing to unset.

Themes

A theme is a set of tokens. Set them on :root, or on any element to theme only what's inside it. 

:root {
  --ui-radius: 0.5rem;
  --ui-spacing: 0.28125rem;
  --ui-primary: light-dark(#0062e0, #4c9aff);
}

Colors follow the page's color-scheme. Set color-scheme: light dark to follow the system, or dark to force it.

Typography

One base size sets the scale. Titles sit 2px above it, labels and descriptions 1px below, and small text 2px below.

Role Sample Size
Title Delete this project?
Base Buttons, inputs, menus and body text.
Label Email address
Description We'll send a confirmation link.

Families

--ui-font-sans The quick brown fox jumps over the lazy dog
--ui-font-mono npm install @ui-sdk/web

Weight and leading

Three weights: 400 for text, 500 for controls and labels, 600 for titles. Running text uses --ui-line-height.

Spacing

A single unit, --ui-spacing. Every padding, gap and height is a multiple of it, so changing it changes the density of everything.

Step Used for Value
× 1 Popup inset
× 1.5 Label to control
× 2 Item padding, icon gap
× 3 Button padding
× 4 Between fields, popover padding
× 6 Dialog padding
× 8 Control height

Size

Controls share one height. Put any of them on a row and they line up, at every spacing and font size.

Radius

One token, --ui-radius, starting at zero. Small parts take half of it and floating surfaces take one and a half, so nested corners stay concentric. Switches and slider thumbs go fully round once the radius is above zero.

½
Checkbox, tracks
1

1½

∞

Elevation

Two levels. The page is flat and separated by borders. Popups add --ui-shadow, and modals add --ui-overlay behind them.

Focus

Keyboard focus draws a 4px --ui-ring right against the control, with no gap. Fields also turn their border to --ui-ring-border. Invalid fields use a red ring. Tab through any example to see it.

Focused field

Icons

The stylesheet draws the four icons components need, as CSS masks in currentColor, so there's no icon library to load. Put your own <svg> in a part and the CSS icon steps aside.

--ui-icon-chevron Select, combobox, accordion, collapsible, navigation menu, submenus
--ui-icon-check Checkbox, selected items, checked menu items
--ui-icon-minus Indeterminate checkbox, number input decrement
--ui-icon-plus Number input increment

Motion

None. Popups appear and disappear at once, switches jump, and nothing fades. Components still set data-starting-style and data-ending-style, so you can add transitions in your own CSS.
