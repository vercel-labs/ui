`ui-sdk-create-component` helps your agent build a component ui-sdk doesn't ship, such as a rating, a stepper, or an emoji picker.

## Install the Skill

If your agent supports skills, install it with:

```bash
npx skills add vercel-labs/ui --skill ui-sdk-create-component
```

The skill also ships inside `@ui-sdk/core`, at `node_modules/@ui-sdk/core/skills/ui-sdk-create-component/SKILL.md`. That copy always matches the version you installed. If your agent doesn't support skills, point it there instead.

## Use the Skill

Mention the skill, your framework, and the interaction you want:

```text
Use ui-sdk-create-component to build a five-star rating in React.
Arrow keys should move between stars and choose a rating.
Use our existing styles and test the keyboard behavior.
```

The skill guides the agent through reading the installed docs, choosing behaviors, defining a primitive, rendering it in your framework, and testing the result. It supports React, Vue, Svelte, Solid, and Web Components.

[Build with an Agent](./build-with-an-agent) shows how to give the agent context, refine the component, and check its work. The [Core guides](../core/build-a-component) explain the code it builds.
