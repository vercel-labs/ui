Find the Core helpers for managing state, adding interactions, and working with the browser. Each section has a small example and links to the relevant guide.

ui-sdk hasn't reached 1.0 yet, so any of these can still change between releases. The ones marked experimental are the likeliest to.

## State and Parts

`definePrimitive` puts a component's state, methods and parts together. Inside its `api`, use `createChange` to report a change:

```ts
import { createChange } from "@ui-sdk/core"

const change = createChange(context)

return {
  mute: () => change("muted", true, { reason: "press" }),
}
```

Calling `mute` reports the new value through `onMutedChange`. The same helper handles both controlled and uncontrolled state, as we saw in [Build a Component](./build-a-component#control-the-state).

- [Define a Primitive](./define-a-primitive) covers options, slots, events and cleanup.
- [State and Changes](./state-and-changes) covers callbacks, controlled state and undo.

## Add an Interaction

Say you're building a row of buttons. `createRovingFocus` gives the row one Tab stop and moves between buttons with the Left and Right arrow keys. Inside the primitive's `api`:

```ts
import { createRovingFocus } from "@ui-sdk/core"

const roving = createRovingFocus(context, {
  slot: "item",
  key: "focused",
  orientation: () => "horizontal",
  loop: () => true,
})
```

This chooses how focus moves. [Focus and Keys](./focus#roving-focus) shows how to connect it to the buttons. [Compose Behaviors](./compose-behaviors) uses it to build the star rating.

## Use a Helper on Its Own

Some helpers work without a primitive. For example, after a copy succeeds, you can announce it to a screen reader:

```ts
import { announce } from "@ui-sdk/core"

announce("Copied")
```

[Platform](./platform) covers announcements, page direction and keyboard shortcuts. [Text](./text) covers searching, matching and language.

To check what you've built, [Testing](./testing) shows how to test state, keyboard behavior and accessibility.
