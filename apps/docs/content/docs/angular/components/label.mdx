A plain `<label>` only reaches inputs, buttons and selects. Label names any control by its `for`, including a radio group or a slider, and a press on the label moves focus into it.

/>

## Installation

```bash
npm install @ui-sdk/angular @ui-sdk/core
```

## Usage

Import the label and point its `for` at the control's `id`:

```ts
import { Component } from "@angular/core"
import { Label } from "@ui-sdk/angular/label"
import { Radio, RadioGroup } from "@ui-sdk/angular/radio"

@Component({
  selector: "app-example",
  imports: [Label, Radio, RadioGroup],
  template: `
    <label uiLabel for="plan">Plan</label>
    <div uiRadioGroup id="plan" defaultValue="pro">
      <button uiRadio value="free">Free</button>
      <button uiRadio value="pro">Pro</button>
    </div>
  `,
})
class Example {}

export { Example }
```

Label renders a native `<label>`. When the browser can reach the control on its own, like an input, it does. For anything else, the control takes the label as its name, and a press on the label focuses it, checks it or clicks it, as a native label would.

Inside a [Field](./field), use `uiFieldLabel`, which also ties the field's description and errors to the control.

## Build Your Own

`@ui-sdk/angular/label` comes with a ready-made Label. If you'd like to build your own, with your own name, start from the `label` primitive in `@ui-sdk/core`:

```ts title="caption.ts"
import { Directive } from "@angular/core"
import { label } from "@ui-sdk/core/label"
import { usePart, usePrimitive } from "@ui-sdk/angular/primitive"

export {}
```

```ts
import { Component } from "@angular/core"
import {} from "./caption"

@Component({
  selector: "app-caption-example",
  imports: [],
  template: ` <div uiCaption for="plan">Plan</div> `,
})
export class CaptionExample {}
```

`Caption` keeps the behavior of the ready-made Label: it names the control and reaches it on a press. See [Rendering Primitives](../rendering) and [Custom Parts](../custom-parts) for more.

## Custom Rendering

Put `uiLabel` on a different element, such as a `<span>`. A label that isn't a `<label>` still names its control and reaches it on a press. See [Parts and Composition](../parts-and-composition) for more.

## Styling

The label is unstyled. It has a `data-slot` of `label`.

A double click on the label doesn't select its text, so you don't need `user-select: none` for that.

## Accessibility

A native `<label>` names the element its `for` points at only when that element is labelable, like an input or a button. Label names any other control through `aria-labelledby`, unless the control has an `aria-label` or an `aria-labelledby` of its own, which win. Its press does what a native label's does: it checks a checkbox, a switch or a radio, focuses a group's checked radio, and focuses anything else. A press on a disabled control does nothing.
