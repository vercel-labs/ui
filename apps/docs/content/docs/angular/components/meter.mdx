Use a Meter for a value within a known range, such as storage used, a battery level or an account quota. It fills a track to show the value, and screen readers announce the same value.

<ComponentExample
  name="meter/basic"
  caption="Read the storage meter. The label names it, and both the visible value and screen reader value report 68%."
/>

## Installation

```bash
npm install @ui-sdk/angular @ui-sdk/core
```

## Composition

Use the following composition to build Meter:

```text
uiMeter
├── uiMeterLabel
├── uiMeterValue
└── uiMeterTrack
    └── uiMeterIndicator
```

- `uiMeter` holds the value and range.
- `uiMeterLabel` gives it a visible name. You can use `aria-label` on the root instead.
- `uiMeterValue` displays the formatted value.
- `uiMeterTrack` gives the bar its size, and `uiMeterIndicator` fills it.

The value is already part of the root's accessible description. The visible value is hidden from screen readers to avoid reading it twice.

## Usage

Import the parts and put them together:

```ts
import { Component } from "@angular/core"
import {
  Meter,
  MeterIndicator,
  MeterLabel,
  MeterTrack,
  MeterValue,
} from "@ui-sdk/angular/meter"

@Component({
  selector: "app-example",
  imports: [Meter, MeterIndicator, MeterLabel, MeterTrack, MeterValue],
  template: `
    <div uiMeter [value]="40">
      <span uiMeterLabel></span>
      <span uiMeterValue></span>
      <div uiMeterTrack>
        <div uiMeterIndicator></div>
      </div>
    </div>
  `,
})
class Example {}

export { Example }
```

## Build Your Own

`@ui-sdk/angular/meter` comes with a ready-made Meter. If you'd like to build your own, with your own names, start from the `meter` primitive in `@ui-sdk/core`:

```ts title="quota.ts"
import { Directive, inject, input, numberAttribute } from "@angular/core"
import { meter } from "@ui-sdk/core/meter"
import { usePart, usePrimitive } from "@ui-sdk/angular/primitive"

@Directive({ selector: "[appQuota]" })
class Quota {
  readonly value = input.required({ transform: numberAttribute })
  readonly handle = usePrimitive(meter, () => ({ value: this.value() }))
  readonly state = usePart(this.handle, "root").state
}

@Directive({ selector: "[appQuotaLabel]" })
class QuotaLabel {
  readonly state = usePart(inject(Quota).handle, "label").state
}

@Directive({ selector: "[appQuotaValue]", exportAs: "appQuotaValue" })
class QuotaValue {
  readonly state = usePart(inject(Quota).handle, "value").state
}

@Directive({ selector: "[appQuotaTrack]" })
class QuotaTrack {
  readonly state = usePart(inject(Quota).handle, "track").state
}

@Directive({ selector: "[appQuotaFill]" })
class QuotaFill {
  readonly state = usePart(inject(Quota).handle, "indicator").state
}

export { Quota, QuotaFill, QuotaLabel, QuotaTrack, QuotaValue }
```

```ts
import { Component } from "@angular/core"
import { Quota, QuotaFill, QuotaLabel, QuotaTrack, QuotaValue } from "./quota"

@Component({
  selector: "app-quota-example",
  imports: [Quota, QuotaFill, QuotaLabel, QuotaTrack, QuotaValue],
  template: `
    <div appQuota [value]="68">
      <span appQuotaLabel>Storage</span>
      <span appQuotaValue #quotaValue="appQuotaValue">{{
        quotaValue.state().text
      }}</span>
      <div appQuotaTrack>
        <div appQuotaFill></div>
      </div>
    </div>
  `,
})
export class QuotaExample {}
```

`uiMeterValue` fills an empty element with the formatted value. A directive of your own leaves its content to you, so show `state().text` in it, as above.

Connect the other slots the same way, each with `usePart`. Each part keeps the behavior, state and data attributes of its ready-made counterpart: the root is the `meter`, and the indicator sets its width from the value. See [Rendering Primitives](../rendering) and [Custom Parts](../custom-parts) for more.

## Bounds

`min` and `max` set the range. They default to 0 and 100. A value outside the range is clamped for the fill, the percentage and `aria-valuenow`, but the state's `value` and a format other than percent keep it as you passed it. Here, 720 sits about 76% of the way from 300 to 850. Decimal formatting keeps the visible value as 720.

## Format and Locale

Pass `Intl.NumberFormat` options to `format` for units, currency, or decimal places. A function can return custom text, such as the number of occupied seats.

<ComponentExample
  name="meter/format"
  caption="Compare the readings. Each meter formats its own value as a unit, currency, custom text, or localized percentage."
/>

A percent format reports the value's position between `min` and `max`. Other formats use the value itself.

`locale` controls digits and separators. If you omit it, the component reads the page's language after it mounts, with the browser's language as a fallback. The initial server and client render use English.

Set `dir="rtl"` on the surrounding content to fill the track from the right.

## Value Label

Use `getValueLabel` when a screen reader needs more context than the visible number. It receives the value and details containing `formatted`, `percent`, `min`, and `max`.

## Changing the Value

Pass a new `value` when your reading changes. Meter follows your state and has no `(beforeValueChange)` callback.

Use [Progress](./progress) for a task that is working toward completion, such as an upload.

## Custom Rendering

See [Parts and Composition](../parts-and-composition) for changing a part's element or reading its state. Use `format` for text that should be shared by the visible value and screen readers.

## Styling

Give the track a height, background, and width. The indicator sets its width as an inline percentage of the track. Both styling options are shown in each example's Code tab.

Each part has a `data-slot`, such as `meter-indicator`, and no state attributes: the reading is in `--meter-value` and the indicator's width.
