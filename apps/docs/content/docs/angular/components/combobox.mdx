Use a Combobox when people need to find a choice by typing. Start with an input and a list, then add chips, server results, or the option to create something new as you need them.

/>

## Installation

```bash
npm install @ui-sdk/angular @ui-sdk/core
```

## Composition

Use the following composition to build Combobox:

```text
uiCombobox
├── uiComboboxLabel
├── uiComboboxInput
└── uiComboboxContent
    └── uiComboboxList
        ├── uiComboboxItem
        └── uiComboboxItem
```

Name the input, give each option a unique value, and put the options in a list inside the popup. The label names the input; choosing an option puts its label in the input.

## Usage

Import the parts and put them together:

```ts
import { Component } from "@angular/core"
import {
  Combobox,
  ComboboxContent,
  ComboboxInput,
  ComboboxItem,
  ComboboxLabel,
  ComboboxList,
} from "@ui-sdk/angular/combobox"

@Component({
  selector: "app-example",
  imports: [
    Combobox,
    ComboboxContent,
    ComboboxInput,
    ComboboxItem,
    ComboboxLabel,
    ComboboxList,
  ],
  template: `
    <ng-container uiCombobox>
      <label uiComboboxLabel>Fruit</label>
      <input uiComboboxInput placeholder="Search fruits…" />
      <div *uiComboboxContent>
        <div uiComboboxList>
          <div uiComboboxItem value="apple">Apple</div>
          <div uiComboboxItem value="banana">Banana</div>
        </div>
      </div>
    </ng-container>
  `,
})
class Example {}

export { Example }
```

## Autocomplete vs Combobox

Both filter a list as you type. They differ in what the value is.

- **Combobox**: the value is an option from the list, or several with `multiple`. The text is only a query; closing without choosing restores the selected label, and a form submits the value, not the text. Use it for a country, an assignee or a set of labels.
- **[Autocomplete](./autocomplete)**: the value is the text. Suggestions help fill it in, and anything typed is valid. Use it for a search box, an address or a free-form field.

`allowCustomValue` lets a combobox accept text that matches no option, like a datalist. Reach for it when choosing from the list is the main path; use an autocomplete when free text is.

## Build Your Own

`@ui-sdk/angular/combobox` comes with a ready-made Combobox. If you'd like to build your own, with your own names, start from the `combobox` primitive in `@ui-sdk/core`:

```ts title="country-picker.ts"
import { Directive, inject, input, type InputSignal } from "@angular/core"
import { combobox, type ComboboxItemProps } from "@ui-sdk/core/combobox"
import { usePart, usePrimitive } from "@ui-sdk/angular/primitive"

@Directive({ selector: "[appCountryPicker]" })
class CountryPicker {
  readonly handle = usePrimitive(combobox, () => ({}))
}

@Directive({ selector: "[appCountryLabel]" })
class CountryLabel {
  readonly state = usePart(inject(CountryPicker).handle, "label").state
}

@Directive({ selector: "[appCountryInput]" })
class CountryInput {
  readonly state = usePart(inject(CountryPicker).handle, "input").state
}

@Directive({ selector: "[appCountryPopup]" })
class CountryPopup {
  readonly state = usePart(inject(CountryPicker).handle, "content").state
}

@Directive({ selector: "[appCountryList]" })
class CountryList {
  readonly state = usePart(inject(CountryPicker).handle, "list").state
}

@Directive({ selector: "[appCountryOption]" })
class CountryOption {
  readonly label: InputSignal<ComboboxItemProps<any>["label"]> = input()
  readonly value = input.required<ComboboxItemProps<any>["value"]>()
  readonly state = usePart(inject(CountryPicker).handle, "item", () => ({
    label: this.label(),
    value: this.value(),
  })).state
}

@Directive({ selector: "[appCountryEmpty]" })
class CountryEmpty {
  readonly state = usePart(inject(CountryPicker).handle, "empty").state
}

export {
  CountryEmpty,
  CountryInput,
  CountryLabel,
  CountryList,
  CountryOption,
  CountryPicker,
  CountryPopup,
}
```

```ts
import { Component } from "@angular/core"
import {
  CountryEmpty,
  CountryInput,
  CountryLabel,
  CountryList,
  CountryOption,
  CountryPicker,
  CountryPopup,
} from "./country-picker"

@Component({
  selector: "app-country-picker-example",
  imports: [
    CountryEmpty,
    CountryInput,
    CountryLabel,
    CountryList,
    CountryOption,
    CountryPicker,
    CountryPopup,
  ],
  template: `
    <ng-container appCountryPicker>
      <label appCountryLabel>Country</label>
      <input appCountryInput />
      <div appCountryPopup>
        <div appCountryEmpty>No countries found.</div>
        <div appCountryList>
          <div appCountryOption value="fr" label="France">France</div>
          <div appCountryOption value="jp" label="Japan">Japan</div>
        </div>
      </div>
    </ng-container>
  `,
})
export class CountryPickerExample {}
```

Connect the other slots the same way, each with `usePart`. Each part keeps the behavior, state and data attributes of its ready-made counterpart: typing filters the options, arrow keys move the highlight and the popup opens in the top layer. See [Rendering Primitives](../rendering) and [Custom Parts](../custom-parts) for more.

## Disabled

A disabled combobox cannot be focused or changed and submits nothing. A read-only one remains focusable and submits its value, but does not open or accept changes. Keyboard navigation skips a disabled option, and it cannot be chosen.

## Clear and Trigger

`uiComboboxClear` clears both the selection and the query, then keeps focus in the input. It appears while either has a value. When someone deletes all the text, a single selection clears right away instead of when the list closes. Escape brings the selection back while the list is still open; closing it any other way leaves it cleared.

## Auto Highlight

Add `autoHighlight` to highlight the first match while typing, so Enter can choose it immediately. With `autoHighlight="always"`, opening the list also highlights the selected item, or the first, so the arrow keys move from there. `autoHighlight="selected"` highlights only the selected item when the list opens, and nothing when none is. A highlight it placed follows the list as items arrive, and one the user moved stays while its item is there.

## Filter and Keywords

`filter` accepts `"contains"` (the default), `"startsWith"`, a function of the item and query, or `false` for results already filtered by a server. A function can return a score instead of `true` or `false`, and items you pass as `items` then sort by it, best first. `fuzzyScore` from `@ui-sdk/core/text-match` scores an exact match above a prefix, and a prefix above a match inside the label.

Use `keywords` for text that should match without appearing in the label, such as a username or a country’s local name.

## Items as Data

Pass `items` when the combobox needs the whole collection, such as recent items, server results, or virtualization. `uiComboboxItems` inside the list renders bare parts for you, or you can render the parts yourself from the list's `state().items`. Each item's `label` supplies the text for filtering and the input; `keywords` and `disabled` work the same as with items you render yourself. [Lists and Menus](../lists-and-menus) covers the `ListData` format.

```ts
import { Component } from "@angular/core"
import { Combobox, ComboboxInput } from "@ui-sdk/angular/combobox"

@Component({
  selector: "app-example",
  imports: [Combobox, ComboboxInput],
  template: `
    <ng-container uiCombobox [items]="fruits">
      <input uiComboboxInput aria-label="Fruit" />
    </ng-container>
  `,
})
class Example {
  readonly fruits = [
    { value: "apple", label: "Apple" },
    { value: "cherry", label: "Cherry", keywords: ["red"] },
    {
      type: "group",
      label: "Citrus",
      items: [{ value: "lemon", label: "Lemon" }],
    },
  ]
}

export { Example }
```

Items can change while the list is open. Selection and highlight stay on their items; removing the highlighted item clears the highlight.

## Object Values

Use `itemToValue` for an object’s string identity and form value, `itemToLabel` for its displayed text, and `isItemEqualToValue` when two different objects can represent the same option.

```ts
import { Component } from "@angular/core"
import { Combobox } from "@ui-sdk/angular/combobox"

type Person = { id: number; name: string }

@Component({
  selector: "app-example",
  imports: [Combobox],
  template: `
    <ng-container
      uiCombobox
      name="reviewer"
      [itemToValue]="itemToValue"
      [itemToLabel]="itemToLabel"
      [isItemEqualToValue]="isItemEqualToValue"
    ></ng-container>
  `,
})
class Example {
  readonly itemToValue = (person: Person) => String(person.id)

  readonly itemToLabel = (person: Person) => person.name

  readonly isItemEqualToValue = (person: Person, value: Person) =>
    person.id === value.id
}

export { Example }
```

## Multiple

Add `multiple` to make the value an array. Choosing an option toggles it, keeps the list open, and clears the query. Put `uiComboboxValue` and the input inside `uiComboboxChips`, then render each value as a chip with a removal button.

Backspace in an empty input removes the last chip in one press. Unlike [Token Input](./token-input#deleting-tokens), there is no `tokenDeletion` option to select it first. Arrow keys move between chips. Supply `itemToLabel` when starting with values whose labels are not yet known from rendered items.

Add `keepQuery` to choose several matches without retyping the query.

## Create Option

`uiComboboxCreate` offers the query when no label matches it exactly and it meets `minLength`. Use `(create)` to save it, and pass a promise to `$event.waitUntil()` for asynchronous work. Creation does not change the selection itself: add the new item and select it after saving.

While saving, the option reports `data-pending`, `aria-busy` and `aria-disabled`. A rejected promise is available through its error state.

## Controlled

The selection, text, and popup have separate values:

| Value   | Change notification   | Meaning                                        |
| ------- | --------------------- | ---------------------------------------------- |
| `value` | `(beforeValueChange)` | One value or `null`; an array with `multiple`. |
| `query` | `(beforeQueryChange)` | The input’s text.                              |
| `open`  | `(beforeOpenChange)`  | Whether the popup is open.                     |

Control only the values you need; `value`, `query` and `open` can also be bound with `[(…)]`. The `before` outputs include a reason and `$event.cancel()` to reject the request. Choosing an item writes its label into the input, and a canceled choice keeps the current one. Closing without choosing restores the value’s label unless custom values are allowed. [State and Events](../state-and-events) covers the binding pattern.

While an input method composes text, like a Japanese conversion or a dead key's accent, the list keeps its filter and `(beforeQueryChange)` gets `$event.composing: true`. Search a server once it's `false`; async options wait for that on their own.

Focus leaving the input closes the popup with the reason `focus-out`, even when code moves it, like a notice that takes focus. To keep the popup open, cancel that close in `(beforeOpenChange)`.

## Positioning

`side` and `align` place the popup around the input or chips. `anchor` can use a different element, and `uiComboboxArrow` follows the side chosen after collision handling. [Popups](../popups#place-the-content) covers offsets and available space.

The page stays usable by default. `modal="pointer"` makes an outside press only dismiss the list; `modal` also locks scrolling and makes the rest of the page inert. The popup uses the top layer and renders in place; use `container` when its DOM belongs elsewhere, such as a shadow root.

## Presentation

Use `presentation="sheet"` for a sheet, or `"auto"` to choose a sheet on small touch screens each time the list opens. The input moves into the sheet’s header; there is still one input and one query.

A touch opening leaves the keyboard closed. Tapping the header input opens the keyboard and grows the sheet; closing the keyboard keeps the query. Choosing an item closes the sheet unless `multiple` is set. Swiping down closes it with the reason `swipe`.

Keep the options inside `uiComboboxList` so the header stays outside the listbox. Give sheet content a height, style it with `data-presentation`, and leave its `translate` for the sheet behavior. `--sheet-backdrop` controls the backdrop. The sheet is modal unless you set `modal` to false; mouse and keyboard openings keep input focus as it moves.

## Forms

A combobox submits the selected value under `name`, rather than the query text. Multiple values submit as separate entries. `required` prevents empty submissions, reset restores the default selection and its label, and `form` joins a form from elsewhere on the page.

The server HTML includes the hidden inputs for the selection, so their values can submit before hydration. [Forms](../forms) covers the shared integration.

In a [Field](./field), the field supplies the input's accessible name, description and error. Submitting a required field without a selection sets `aria-invalid` and `data-invalid`.

### Events

A `before` output emits `{ value, reason, event, cancel() }` before the change, and its plain output follows with the value alone. A bound value only updates when the change isn't canceled.

| Binding                | On                 | Receives                                                                                               |
| ---------------------- | ------------------ | ------------------------------------------------------------------------------------------------------ |
| `[(value)]`            | `uiCombobox`       | The selected value                                                                                     |
| `[(query)]`            | `uiCombobox`       | The input's text                                                                                       |
| `[(open)]`             | `uiCombobox`       | Whether the list is open                                                                               |
| `(beforeValueChange)`  | `uiCombobox`       | `{ value, reason, cancel() }`: the new value, and the [reason](#reasons)                               |
| `(beforeQueryChange)`  | `uiCombobox`       | `{ value, reason, cancel() }`: the new text, the [reason](#reasons) and whether it's still `composing` |
| `(beforeOpenChange)`   | `uiCombobox`       | `{ value, reason, cancel() }`: the new state, and the [reason](#reasons)                               |
| `(openChangeComplete)` | `uiCombobox`       | `$event`, whether it's open, after the animation                                                       |
| `(highlight)`          | `uiCombobox`       | `{ value, index, event }`: the highlighted item and its row                                            |
| `(loadMore)`           | `uiCombobox`       | `()`, when the last item is reached                                                                    |
| `(dismissAttempt)`     | `uiCombobox`       | `{ reason, event }`, when a dismissal was refused                                                      |
| `(create)`             | `uiComboboxCreate` | `{ query, waitUntil() }`: the text. `waitUntil(promise)` marks it pending                              |

## Accessibility

The combobox follows the [WAI-ARIA combobox pattern with list autocomplete](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/examples/combobox-autocomplete-list/). Focus usually stays in the input while `aria-activedescendant` identifies the highlighted option. A touch screen-reader trigger can move real focus into the list, and a sheet has its own [focus behavior](#presentation). Every line below is an automated test.

### Keyboard

| Key                   | Does                                                                    |
| --------------------- | ----------------------------------------------------------------------- |
| Typing                | Filters the options and opens the list                                  |
| ArrowDown, ArrowUp    | Opens the list, then moves the highlight. Wraps unless `[loop]="false"` |
| Enter                 | Chooses the highlighted option                                          |
| Escape                | Closes the list, then restores the selection's label                    |
| Backspace             | In an empty input with chips, removes the last chip                     |
| ArrowLeft, ArrowRight | Moves between chips, reversed in right-to-left text                     |
