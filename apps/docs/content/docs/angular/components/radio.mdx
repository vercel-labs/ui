Use radios for a short list of choices where only one can be picked, like a shipping speed or a plan. The group keeps one value and gives the whole list a single tab stop.

/>

## Installation

```bash
npm install @ui-sdk/angular @ui-sdk/core
```

## Composition

Use the following composition to build RadioGroup:

```text
uiRadioGroup
├── uiRadio
│   └── uiRadioIndicator
└── uiRadio
    └── uiRadioIndicator
```

Give each radio a `value` and wrap it with its text in a label. The group's value is the checked radio's value, and the indicator shows while its radio is checked.

## Usage

Import the parts and put them together:

```ts
import { Component } from "@angular/core"
import { Field, FieldLabel } from "@ui-sdk/angular/field"
import { Radio, RadioGroup, RadioIndicator } from "@ui-sdk/angular/radio"

@Component({
  selector: "app-example",
  imports: [Field, FieldLabel, Radio, RadioGroup, RadioIndicator],
  template: `
    <div uiField>
      <label uiFieldLabel>Shipping speed</label>
      <div uiRadioGroup defaultValue="standard">
        <label>
          <button uiRadio value="standard">
            <span uiRadioIndicator></span>
          </button>
          Standard
        </label>
        <label>
          <button uiRadio value="express">
            <span uiRadioIndicator></span>
          </button>
          Express
        </label>
      </div>
    </div>
  `,
})
class Example {}

export { Example }
```

The field's label names the group. Without a field, name it with `aria-label` or `aria-labelledby`. Without `defaultValue`, nothing starts checked and Tab enters on the first enabled radio.

## Disabled

Set `disabled` on the group or on one radio. Disabled radios can't be focused or checked, and arrow keys skip them. A disabled fieldset disables the group too, and a disabled group submits nothing.

## Controlled

Use `[(value)]` to own the value, and `(beforeValueChange)` for the reason. Call `$event.cancel()` in the callback to keep the current value. A [controller](#controller) from `createRadioGroupController()` checks a radio from anywhere, like the Choose Team button below. Create one controller per mounted group.

## Form

Each radio renders a button with the `radio` role and a hidden native radio, so the group takes part in forms. Set `name` to submit the checked value; the group submits nothing without a name or a checked radio. `required` blocks submission until there's a choice, and a reset returns to `defaultValue`.

Set `form` to a form's id to join it from elsewhere on the page, as this group does.

## Animation

The indicator has `data-starting-style` as it appears and `data-ending-style` while it leaves, and stays mounted until its exit finishes. Transition from those states:

<StyleTabs>

```css
[data-slot="radio-indicator"] {
  transition:
    opacity 0.15s,
    scale 0.15s;

  &:is([data-starting-style], [data-ending-style]) {
    opacity: 0;
    scale: 0.5;
  }
}
```

```angular-html
<span
  uiRadioIndicator
  class="transition-[opacity,scale] duration-150 data-starting-style:scale-50 data-starting-style:opacity-0 data-ending-style:scale-50 data-ending-style:opacity-0"
></span>
```

</StyleTabs>

## Loop

Arrow keys wrap from the last radio to the first. Set `loop` to `false` to stop at the ends.

```angular-html
<div uiRadioGroup defaultValue="low" [loop]="false">...</div>
```

## Styling

Use `data-checked` and `data-unchecked` for the checked state, and `data-disabled`, `data-readonly` and `data-required` for the rest. The indicator gets the same state attributes as its radio, and the group gets `data-disabled`, `data-readonly` and `data-required`.

### Events

A `before` output emits `{ value, reason, event, cancel() }` before the change, and its plain output follows with the value alone. A bound `value` only updates when `(beforeValueChange)` wasn't canceled.

| Binding               | On             | Receives                                                                     |
| --------------------- | -------------- | ---------------------------------------------------------------------------- |
| `[(value)]`           | `uiRadioGroup` | The checked value                                                            |
| `(beforeValueChange)` | `uiRadioGroup` | `{ value, reason, cancel() }`: the checked value, and the [reason](#reasons) |

## Accessibility

Radio groups follow the [WAI-ARIA radio group pattern](https://www.w3.org/WAI/ARIA/apg/patterns/radio/), and behave like native radios that share a name. `uiRadio` renders a button with the `radio` role, and a hidden native radio that takes part in forms.

### Keyboard

| Key        | Does                                                                    |
| ---------- | ----------------------------------------------------------------------- |
| Tab        | Moves into the group, onto the checked radio or the first enabled one   |
| Arrow keys | Move to the next or previous radio and check it, skipping disabled ones |
| Space      | Checks the focused radio                                                |
| Enter      | Submits its form                                                        |
