Let's add a Bookmark toggle. Press it once to turn it on, then again to turn it off.

If you haven't installed the packages yet, start with [Installation](./installation).

## Create the Component

Create `bookmark-button.svelte` next to your app component and render a `Toggle`:

```svelte title="bookmark-button.svelte"
<script lang="ts">
  import { Toggle } from "@ui-sdk/svelte/toggle"
</script>

<Toggle>Bookmark</Toggle>
```

`Toggle` renders a button. It keeps track of its pressed state, handles Enter and Space, and sets `aria-pressed` for screen readers.

## Use It in Your App

In your app component (`App.svelte` here), import and render `BookmarkButton`:

```svelte title="App.svelte"
<script lang="ts">
  import BookmarkButton from "./bookmark-button.svelte"
</script>

<BookmarkButton />
```

Open your app. You should see a button labeled Bookmark. Next, add styles so you can tell when it is pressed.

## Add Styles

When the toggle is pressed, it has a `data-pressed` attribute. Use that attribute to change its appearance.

With Tailwind CSS configured in your app, add utility classes to `class`. The `data-pressed:` variant applies while the toggle is pressed:

```svelte title="bookmark-button.svelte"
<script lang="ts">
  import { Toggle } from "@ui-sdk/svelte/toggle"
</script>

<Toggle class="inline-flex h-8 items-center rounded-md border border-neutral-300 px-3 text-sm font-medium hover:bg-neutral-100 focus-visible:outline-2 focus-visible:outline-offset-2 data-pressed:bg-neutral-900 data-pressed:text-white">
  Bookmark
</Toggle>
```

Try the styled toggle:

<ComponentExample
  name="toggle/first-component"
  hideCode={true}
  caption="Click Bookmark to turn it on or off. A filled background means it is on. You can also focus the button with Tab and press Enter or Space."
/>

Keep the label the same in both states. `aria-pressed` tells a screen reader whether the toggle is on.
