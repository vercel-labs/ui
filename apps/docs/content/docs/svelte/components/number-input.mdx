## Installation

```bash
pnpm add @ui-sdk/svelte @ui-sdk/core
```

The examples use the [shared example theme](../styling-and-animation#example-theme). The examples use `@lucide/svelte` for icons.

## Anatomy

```svelte
<script lang="ts">
  import { NumberInput, NumberInputGroup, NumberInputControl, NumberInputDecrement, NumberInputIncrement } from "@ui-sdk/svelte/number-input"
</script>

<NumberInput defaultValue={1} min={0}>
  <NumberInputGroup>
    <NumberInputDecrement aria-label="Decrease">−</NumberInputDecrement>
    <NumberInputControl aria-label="Quantity" />
    <NumberInputIncrement aria-label="Increase">+</NumberInputIncrement>
  </NumberInputGroup>
</NumberInput>
```

`NumberInput` holds the numeric value. `NumberInputGroup` wraps the text input and optional step buttons. `NumberInputControl` renders the input; `NumberInputDecrement` and `NumberInputIncrement` change its value.

### Buttons

The step buttons repeat while held. They stay out of the Tab order because the focused input provides the same stepping actions through its arrow keys. Give each button an accessible name.

Typing updates the numeric value when the text is valid and within bounds. Enter or blur commits it: the text is parsed, clamped, snapped to the step, and formatted. An empty input has the value `null`.

### Step and Large Step

`step` sets the usual increment. Steps are measured from `min`, or from zero when no minimum is set.

| Input                                               | Increment                                         |
| --------------------------------------------------- | ------------------------------------------------- |
| ArrowUp, ArrowDown, or a step button                | `step`, which defaults to 1.                      |
| Shift with an arrow or button; Page Up or Page Down | `largeStep`, which defaults to ten steps.         |
| Alt (Option) with an arrow key                      | `smallStep`, which defaults to a tenth of a step. |
| Home or End                                         | The minimum or maximum, when set.                 |

### Scrub Area

`NumberInputScrubArea` changes the value while you drag. Right and up increase it. `orientation` chooses an axis, and `pixelsPerStep` controls how far the pointer moves per step. Shift and Alt (Option) use the large and small increments.

<ComponentExample
  name="number-input/scrub"
  caption="Drag Width horizontally or Height vertically. Hold Shift for larger steps or Alt (Option) for smaller ones. Click either label without dragging to select its input text."
/>

Where pointer lock is available, the drag can continue past the edge of the screen. `NumberInputScrubAreaCursor` draws a replacement cursor while it is locked. The cursor is placed in the document body with an inline translation; center your icon with negative margins.

## Behavior and Options

### Controlled

Use `bind:value` to bind the value. `onValueChange` also receives the change details. `onValueChange` reports valid changes while an interaction is in progress. `onValueCommit` runs when typing is committed, a step key or button is released, or a scrub ends. Use the commit event for work that should happen after the interaction.

<ComponentExample
  name="number-input/controlled"
  caption="Edit Servings or hold a step button. Value updates as it changes; Committed updates when the interaction ends. Clear sets the value to null, and Reset to 4 restores it."
/>

See [State and Events](../state-and-events) for the shared state conventions and [Reasons](#reasons) for the events specific to Number Input.

### Controller

Create a `createNumberInputController()` and pass it as `controller` to change or focus the input from other controls. `increment()` and `decrement()` step the value; pass `{ large: true }` for a large step. `setValue()`, `getValue()`, and `focus()` cover direct updates and inspection.

<ComponentExample
  name="number-input/controller"
  caption="Try Zoom in and Zoom out, then Actual size to restore 100. Read reports the current value, and Focus moves into the field."
/>

[Controllers](../controllers) covers creating and sharing a controller.

## Forms

A hidden input submits the plain numeric value under `name`. Formatting does not change form data: a displayed currency amount still submits a value such as `1234.5`. Empty values submit an empty string.

<ComponentExample
  name="number-input/form"
  caption="Change Quantity or Tip and choose Save to read the plain numeric values. Gift cards belongs to the same form through its form ID. Reset restores the defaults."
/>

Set `form` to associate the input with a form elsewhere in the page. A form reset restores the default value and reports the `reset` reason.

## API Reference

Props are the same as below. `value` is bindable.

### Events

Callbacks get the new value first, then the details. A bound `value` only updates when `onValueChange` didn't cancel the change.

| Prop            | On            | Receives                                                                          |
| --------------- | ------------- | --------------------------------------------------------------------------------- |
| `bind:value`    | `NumberInput` | The value, or null when empty                                                     |
| `onValueChange` | `NumberInput` | `(value, details)`: the new value, or null when empty, and the [reason](#reasons) |
| `onValueCommit` | `NumberInput` | `(value, details)`: the value once the interaction ends, and its reason           |
