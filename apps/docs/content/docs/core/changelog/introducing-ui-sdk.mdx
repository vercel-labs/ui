Today we're releasing UI SDK.

UI SDK is a TypeScript library of UI behaviors, the layers that make up a component library. It provides building blocks for keyboard navigation, focus, selection, popups, drag and drop, and the ARIA attributes those interactions need.

For example, `createRovingFocus` moves focus with the arrow keys, `createTypeahead` finds an option as you type, and `createPopup` opens a popup next to its button.

We built more than 50 of them. You, or your agent, combine them to build your own components.

## Build a component

Here's a small popover. You define it once with `@ui-sdk/core`, and `createPopup` does the hard part: it opens next to its button, closes on Escape or a click outside, and puts focus back where it was.

```ts title="lib/share.ts"
import {
  createPopup,
  definePrimitive,
  popupContent,
  popupState,
  popupTrigger,
} from "@ui-sdk/core"
import { popoverPreset } from "@ui-sdk/core/popover"

const share = definePrimitive({
  name: "share",
  options: { defaultOpen: "boolean" },
  state: (options: { defaultOpen?: boolean }) => popupState(options),
  api: (context) => createPopup(context, { preset: popoverPreset }),
  slots: (slot) => ({
    trigger: popupTrigger(slot),
    content: popupContent(slot),
  }),
})

export { share }
```

Don't worry, you don't have to learn to write this. We taught agents how to do it, and they're really good at it. Ask yours for the component you need.

## Component libraries

We used the same behaviors to build a component library for every framework: more than 50 ready-made components, from a Select to a Date Picker, with the same parts in React, Vue, Svelte, Solid and Web Components. You bring the styles.

## Agents

These days, agents build our interfaces. And more and more, agents use them too. So we built UI SDK for both.

Everything you build with UI SDK is easy for an agent to use. An agent can read what's on the page and press, type and pick, just like a person would, within the permissions you set.

Give an agent your page with `createAgent`:

```ts
import { createAgent } from "@ui-sdk/react/agent"

const agent = createAgent({
  allow: ({ component, label, action }) =>
    component === "select" && label === "Region" && action === "setValue",
})

agent.snapshot()

await agent.act({
  steps: [{ ref: "Region", action: "setValue", args: ["north-america"] }],
})
```

WebMCP lets a page give tools to the agent built into a browser. Call `registerTools` and the browser's agent can read your components and call their actions too. To set it up, read [WebMCP](/docs/agents/connect-an-agent/webmcp).
