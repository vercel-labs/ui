## Focus and Keys

| Helper                                                               | What It Does                                                             |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| [`createRovingFocus`](./focus#roving-focus)                          | Gives a group one Tab stop and moves focus with the arrow keys.          |
| [`createGridFocus`](./focus#grids)                                   | Moves focus by row and column, including cells that aren't rendered yet. |
| [`spatialMove`](./focus#spatial-focus)                               | Chooses the next item from its position on screen.                       |
| [`nearestInDirection`](./focus#choose-a-target-without-moving-focus) | Finds the nearest item in a direction without moving focus.              |
| [`createTypeahead`](./focus#typeahead)                               | Finds an item as someone types its name.                                 |
| [`isTypeaheadKey`](../text#find-an-item-by-typing)                   | Checks whether a key can be used for typeahead.                          |
| [`labelOf`](../text#what-an-item-is-called)                          | Reads an element's label for matching typed text.                        |
| [`createFocusRecovery`](./focus#focus-recovery)                      | Restores focus when the focused item is removed.                         |
| [`keepFocus`](./focus#focus-that-follows-a-move)                     | Preserves focus through a change that moves an element.                  |

## Popups and Layers

| Helper                                                               | What It Does                                                           |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| [`createPopup`](./popups#make-your-own)                              | Manages opening, closing, positioning, and focus using a popup preset. |
| [`popupState`](./popups#a-popup-of-your-own)                         | Creates the initial open, mounted, and payload state.                  |
| [`popupTrigger`](./popups#a-popup-of-your-own)                       | Builds a trigger slot that opens and closes the popup.                 |
| [`popupContent`](./popups#a-popup-of-your-own)                       | Builds a content slot with presence, placement, and focus handling.    |
| [`popupClose`](./popups#a-popup-of-your-own)                         | Builds a slot that closes the popup.                                   |
| [`popupTitle`](./popups#one-popup-many-triggers)                     | Connects a visible title to the popup's accessible name.               |
| [`popupDescription`](./popups#one-popup-many-triggers)               | Connects descriptive text to the popup.                                |
| [`popupArrow`](./popups#one-popup-many-triggers)                     | Builds an arrow slot that follows the popup's placement.               |
| [`popupBackdrop`](./popups#every-part-and-parts-of-your-own)         | Builds a backdrop slot behind a modal popup.                           |
| [`popupViewport`](./popups#every-part-and-parts-of-your-own)         | Builds a full-screen container slot for a popup sheet.                 |
| [`popupSlots`](./popups#every-part-and-parts-of-your-own)            | Builds the standard popup parts together.                              |
| [`position`](./popups#placing-a-popup)                               | Places an element beside an anchor and updates its placement.          |
| [`bindLayer`](./popups#layers-of-your-own)                           | Registers a floating element for Escape and outside-press dismissal.   |
| [`bindPersistentLayer`](./popups#modal-layers-and-what-stays-usable) | Keeps an element usable across layers, including modal popups.         |
| [`isDismissal`](./popups#modal-layers-and-what-stays-usable)         | Identifies a dismissal reason, such as Escape or an outside press.     |
| [`supportsTopLayer`](./popups#types-and-the-top-layer)               | Checks whether the browser supports the top layer used by popups.      |

[Popup presets](./popups#pick-its-behavior) choose the interaction for a popover, dialog, tooltip, or hover card. [Popup controllers](./popups#open-from-code) open existing popup components from code and wait for a result. Import each from its component entrypoint, such as `@ui-sdk/core/popover`.
