Use a rating to collect a score, like how a stay went, or to show one, like an average. Each star is a radio, so it works like a radio group, with one value and a single tab stop.

<ComponentExample
  name="rating/basic"
  caption="Choose a star, then use the arrow keys to change the score."
/>

## Installation

```bash
npm install @ui-sdk/vue @ui-sdk/core
```

## Composition

Use the following composition to build a `Rating`:

```text
Rating
└── RatingItem
```

`Rating` renders its default slot once per star, so put one `RatingItem` inside it. Without a slot, it renders a `RatingItem` with no icon.

## Usage

Import the parts and put them together:

```vue
<script setup lang="ts">
import { StarIcon } from "@lucide/vue"
import { Rating, RatingItem } from "@ui-sdk/vue/rating"
</script>

<template>
  <Rating aria-label="Rating" :default-value="3">
    <RatingItem>
      <StarIcon aria-hidden="true" />
    </RatingItem>
  </Rating>
</template>
```

Name the rating with `aria-label`, or put it in a [Field](./field) whose label names it. Without `default-value`, nothing starts checked and Tab enters on the first star.

## Stars

Put your icon in `RatingItem`. Each item says how much of its star the shown score covers: `--rating-fill` goes from 0 to 1, `data-filled` marks a whole star and `data-partial` the star a score ends partway through. The radios that pick the score sit over the icon, so it needs no events of its own.

```css
[data-slot="rating-item"] {
  color: lightgray;
}

[data-slot="rating-item"][data-filled] {
  color: gold;
}
```

For half stars and averages, paint the icon up to `calc(var(--rating-fill) * 100%)`, like with a gradient behind a star-shaped mask.

The item's default slot gets its `state`, so an icon can fill once the score covers the star:

```vue
<RatingItem v-slot="{ state }">
  <StarIcon aria-hidden="true" :fill="state.fill === 1 ? 'currentColor' : 'none'" />
</RatingItem>
```

## Half Stars

Set `:step="0.5"` to split each star in two. Each half is its own radio, named like "2.5 stars", and a press on the first half of a star picks the half score.

## Preview

While a pointer moves over the stars, they show the score under it: `--rating-fill` follows the pointer, and `data-highlighted` marks the stars up to it. Leaving the stars shows the score again. Touch has no preview, since a tap picks the score at once.

## Deselectable

Set `deselectable` to let people clear their score: a press on the checked star, or Space on it, sets the score back to `null`.

## Read-Only

Set `read-only` to show a score that can't change, like an average. Any score shows, like 4.2, which fills a fifth of the last star. The rating becomes one image for screen readers, and its radios are hidden from them.

Name a read-only rating with `get-value-label`, so its name includes the score. An `aria-label` would replace it.

<ComponentExample
  name="rating/read-only"

## Controlled

Bind `v-model:value`, and listen to `@value-change` for the reason. Call `details.cancel()` in the listener to keep the current score. A [controller](#controller) from `createRatingController()` sets the score from anywhere, like the Clear Rating button below. Create one controller per mounted rating.

## Form

Each radio renders a hidden native radio, so the rating takes part in forms. Set `name` to submit the score; nothing submits without a name or a score. `required` blocks submission until there's a score, and a reset returns to `default-value`.

<ComponentExample
  name="rating/form"

/>

## Stars and Labels

Set `max` for the number of stars, and `loop` to let the arrow keys wrap from the last star to the first. Each radio is named by `get-value-label`, which gets the score and `max` and says "1 star" or "3 stars" by default.

```vue
<Rating
  aria-label="Difficulty"
  :max="10"
  loop
  :get-value-label="(value, max) => `${value} of ${max}`"
/>
```

### Events

Events get the new score first, then the details. `v-model` only updates when the change event wasn't canceled.

| Binding         | On       | Receives                                                            |
| --------------- | -------- | ------------------------------------------------------------------- |
| `v-model:value` | `Rating` | The score, or `null`                                                |
| `@value-change` | `Rating` | `(value, details)`: the score or `null`, and the [reason](#reasons) |

## Accessibility

A rating is a radio group, so it follows the [WAI-ARIA radio group pattern](https://www.w3.org/WAI/ARIA/apg/patterns/radio/) and behaves like native radios that share a name. Each star holds a button with the `radio` role per score it can pick, and a hidden native radio that takes part in forms. Icons inside the stars should be hidden from screen readers with `aria-hidden`, since each radio is already named. A read-only rating has the `img` role instead, named by `get-value-label`.

### Keyboard

| Key        | Does                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------ |
| Tab        | Moves into the rating, onto the checked star or the first one                              |
| Arrow keys | Move to the next or previous score and check it, stopping at the ends unless `loop` is set |
| Space      | Checks the focused star, or clears it when it's checked and `deselectable`                 |
| Enter      | Submits its form                                                                           |
