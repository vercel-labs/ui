Use a checkbox for a choice someone can check or uncheck. Use a group when several choices belong to one value.

<ComponentExample
  name="checkbox/basic"
  caption="Click the checkbox or its label, or focus it and press Space, to accept the terms."
/>

## Installation

```bash
npm install @ui-sdk/vue @ui-sdk/core
```

## Composition

Use the following composition to build a `Checkbox`:

```text
Checkbox
└── CheckboxIndicator
```

Wrap the checkbox and its text in a label. The indicator shows while the checkbox is checked or mixed.

`Checkbox` renders a button with the `checkbox` role and a hidden native checkbox that handles forms.

### Indeterminate

An indeterminate checkbox represents a partly checked set. It has `aria-checked="mixed"` and `data-indeterminate`. A press checks it; only your code puts it back into the mixed state.

Start with `defaultChecked="indeterminate"`, or pass `"indeterminate"` as the controlled value. The indicator's state tells it which icon to show. A [parent checkbox](#parent-checkbox) derives this state from a group for you.

### Controlled

Use `v-model:checked` to own the value. A `createCheckboxController()` lets another button change it. [State and Events](../state-and-events) covers canceling changes and choosing who owns the value.

## Forms

Set `name` and `value` to include a checked checkbox in a native form. Unchecked and mixed checkboxes submit nothing. The default value is `"on"`.

`required` blocks submission until the checkbox is checked. Reset returns it to `defaultChecked`. Set `form` to a form's id to join it from elsewhere on the page. Space toggles the checkbox; Enter submits its form.

<ComponentExample
  name="checkbox/form"
  caption="Submit with the terms unchecked to see native validation. Accept the terms and submit; Reset restores the defaults and clears the result. The newsletter checkbox belongs to the same form from outside it."
/>

## Group

`CheckboxGroup` keeps one list of checked values. Each checkbox supplies its `value`; the group returns selected values in the order the checkboxes appear. Name the group with `aria-label`, `aria-labelledby`, or a [Field](#group-in-a-field).

<ComponentExample
  name="checkbox/group"
  caption="Choose several toppings. The group keeps one list of checked values."
/>

### Parent Checkbox

Add a checkbox with `parent` to check or uncheck the group. It is checked when every value is selected, unchecked when none are, and mixed in between. It points to its children with `aria-controls` and submits nothing itself.

Pass `allValues` to the group so the parent has the right state on the first render, including on the server. Otherwise it discovers the values after the checkboxes mount.

<ComponentExample
  name="checkbox/group-parent"
  caption="Select all checks every topping. Uncheck one topping to put Select all into its mixed state."

### Events

Events get the new state or value first, then the details. `v-model` only updates when the change event wasn't canceled.

| Binding           | On              | Receives                                                           |
| ----------------- | --------------- | ------------------------------------------------------------------ |
| `v-model:checked` | `Checkbox`      | The checked state                                                  |
| `@checked-change` | `Checkbox`      | `(checked, details)`: the new state, and the [reason](#reasons)    |
| `v-model:value`   | `CheckboxGroup` | The checked values                                                 |
| `@value-change`   | `CheckboxGroup` | `(value, details)`: the checked values, and the [reason](#reasons) |
