## Usage

Use `@click` to run an action. Button renders a native `<button>` with `type="button"` by default.

```vue
<script setup lang="ts">
import { Button } from "@ui-sdk/vue/button"
import { ref } from "vue"

const count = ref(0)
</script>

<template>
  <div>
    <Button @click="count++">Button</Button>
    <output>Pressed {{ count }} {{ count === 1 ? "time" : "times" }}</output>
  </div>
</template>
```

## Pending

Return a Promise from `@click` to keep the button pending until it settles. `@click` binds to a prop, so Button receives the handler’s return value. The button keeps focus and ignores further presses while it waits.

```vue
<script setup lang="ts">
import { Button } from "@ui-sdk/vue/button"

const save = () => new Promise((resolve) => setTimeout(resolve, 1500))
</script>

<template>
  <Button @click="save" pending-announcement="Saving">Save</Button>
</template>
```

After one second, it announces "Loading" to screen readers. Set `pending-announcement` to change that message, as above, or use an empty string to silence it.

The demo uses `LoaderCircle` from `@lucide/vue` for its spinner. Install that package if you copy the example:

```bash
npm install @lucide/vue
```

### Handling Errors

If the handler throws or its Promise rejects, `state.error` holds the error. Use it to show a message or a retry label. The next press clears the error and runs the handler again.

The demo uses a [`#render` slot](/docs/vue/parts-and-composition#read-the-state) to show the error beside the button. The default slot receives the state too.

### Changes After an Await

`@click` receives the event and `{ source }`, which says how the button was pressed. If the handler changes another ui-sdk component after an `await`, wrap that change in `withSource` to keep the original source. Otherwise, the later change is reported as `"programmatic"`.

Here `save()` is your request and `status` is an Input's [controller](/docs/vue/controllers):

```vue
<script setup lang="ts">
import { Button, type ButtonActionDetails } from "@ui-sdk/vue/button"
import { withSource } from "@ui-sdk/vue/observe"

async function onSave(event: MouseEvent, { source }: ButtonActionDetails) {
  await save()
  withSource(source, () => status.setValue("Saved"))
}
</script>

<template>
  <Button @click="onSave">Save</Button>
</template>
```

[Observe](/docs/core/observe#keep-the-source-after-an-await) explains source tracking. Preserving `"agent"` lets [`undoSource("agent")`](/docs/agents/connect-an-agent/history-and-undo#undo-the-agents-changes) include that later change.

## Disabled

Set `disabled` to prevent presses and remove the button from the tab order. A disabled `<fieldset>` around the button disables it too.

```vue
<Button disabled>Disabled</Button>
```

### Focusable When Disabled

Add `focusable-when-disabled` when people should still be able to focus a disabled button. It uses `aria-disabled` instead of the native `disabled` attribute. Presses still do nothing.

Use `aria-describedby` to explain why the action is unavailable:

```vue
<Button disabled focusable-when-disabled>
  <template #render="{ props }">
    <button v-bind="props" aria-describedby="publish-hint">Publish</button>
  </template>
</Button>
<p id="publish-hint">Add a title to publish.</p>
```

## Links

Use the `#render` slot to render an `<a>`, and bind the supplied `props` to it. It keeps its `href` and link semantics, including opening in a new tab. A disabled link cannot navigate and leaves the tab order.

```vue
<Button>
  <template #render="{ props }">
    <a v-bind="props" href="/docs/vue">Get started</a>
  </template>
</Button>
```

## Forms

Set `type="submit"` to submit a form or `type="reset"` to restore its default values. The default, `type="button"`, does neither.

```vue
<Button type="submit">Subscribe</Button>
<Button type="reset">Reset</Button>
```

<ComponentExample
  name="button/form"
  caption="Edit the email and choose Subscribe, or press Enter in the field, to submit it. Reset restores the original email and clears the result."
/>

Button tracks the Promise returned by its own `@click`. An async form submission needs its own pending state; see [Forms](/docs/vue/forms).

## Custom Rendering

The `#render` slot receives `{ props, state, children }`. Bind `props` to your element, and render `<component :is="children" />` when you need the part’s original children. [Parts and Composition](/docs/vue/parts-and-composition) shows how to compose your own components.
