Use a collapsible to show and hide one panel of content. For a set of panels, use an [accordion](./accordion).

<ComponentExample

/>

## Installation

```bash
npm install @ui-sdk/vue @ui-sdk/core
```

## Composition

Use the following composition to build a `Collapsible`:

```text
Collapsible
├── CollapsibleTrigger
└── CollapsiblePanel
```

The root and panel render divs, and the trigger renders a native button. Put other content around them, like a heading or a summary that always shows.

## Usage

Import the parts and put them together:

```vue
<script setup lang="ts">
import {
  Collapsible,
  CollapsiblePanel,
  CollapsibleTrigger,
} from "@ui-sdk/vue/collapsible"
</script>

<template>
  <Collapsible>
    <CollapsibleTrigger>Order details</CollapsibleTrigger>
    <CollapsiblePanel>2 × Linen shirt</CollapsiblePanel>
  </Collapsible>
</template>
```

## Build Your Own

`@ui-sdk/vue/collapsible` comes with a ready-made Collapsible. If you'd like to build your own, with your own names, start from the `collapsible` primitive in `@ui-sdk/core`:

```ts title="spoiler.ts"
import { collapsible } from "@ui-sdk/core/collapsible"
import { createParts } from "@ui-sdk/vue/primitive"

const {
  Root: Spoiler,
  Trigger: SpoilerToggle,
  Panel: SpoilerContent,
} = createParts(collapsible, {
  root: "div",
  trigger: "button",
  panel: "div",
})

export { Spoiler, SpoilerContent, SpoilerToggle }
```

```vue
<template>
  <Spoiler>
    <SpoilerToggle>Show the ending</SpoilerToggle>
    <SpoilerContent>The butler did it.</SpoilerContent>
  </Spoiler>
</template>
```

Each part keeps the behavior, state and data attributes of its ready-made counterpart. See [Rendering](../rendering) and [Custom Parts](../custom-parts) for more.

## Disabled

Set `disabled` on the root to stop its trigger from opening or closing the panel. The trigger stays in the tab order and reports `aria-disabled="true"`. A disabled `<fieldset>` around the collapsible disables it too.

```vue
<Collapsible disabled>
  <CollapsibleTrigger>Gift options</CollapsibleTrigger>
  <CollapsiblePanel>Add a gift message and wrapping.</CollapsiblePanel>
</Collapsible>
```

## Keep Mounted

Panels unmount when they close, so Tab skips their contents. Set `keep-mounted` on the panel to keep it mounted and hidden, so a field keeps what you typed into it.

## Find in Page

Set `hidden-until-found` on the panel to keep it in the DOM as `hidden="until-found"`. Browser Find and links to content inside the panel can reveal it. The panel opens without an animation so the match is visible immediately.

Vue renders `hidden="until-found"` on the server, so the closed panel is findable before hydration.

  name="collapsible/find-in-page"

/>

## Controlled

Use `v-model:open` to own the open state. `@open-change` also gets the change details: call `details.cancel()` in it to cancel the change.

For a button elsewhere on the page, create a [controller](#controller) with `createCollapsibleController()` and pass it as `controller`. Create one controller per mounted collapsible.

## Animation

Animate the measured `--collapsible-panel-height` between zero and the content's height. `data-starting-style` marks the opening frame, and `data-ending-style` stays on while it closes. The panel stays mounted until its closing animation finishes, and a panel open on its first paint doesn't animate.

<StyleTabs>

```css
[data-slot="collapsible-panel"] {
  height: var(--collapsible-panel-height);
  overflow: hidden;
  transition: height 0.2s ease-out;

  &:is([data-starting-style], [data-ending-style]) {
    height: 0;
  }
}
```

```vue
<CollapsiblePanel
  class="h-(--collapsible-panel-height) overflow-hidden transition-[height] duration-200 ease-out data-starting-style:h-0 data-ending-style:h-0"
/>
```

</StyleTabs>

`@open-change-complete` reports when opening or closing has finished.

### Events

Events get the new state first, then the details. `v-model` only updates when `@open-change` wasn't canceled.

| Binding                 | On            | Receives                                                     |
| ----------------------- | ------------- | ------------------------------------------------------------ |
| `v-model:open`          | `Collapsible` | Whether the panel is open                                    |
| `@open-change`          | `Collapsible` | `(open, details)`: the new state, and the [reason](#reasons) |
| `@open-change-complete` | `Collapsible` | `(open)`, after the panel's animation                        |

## Accessibility

The collapsible follows the [WAI-ARIA disclosure pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/). The trigger says whether the panel is open with `aria-expanded`, and points to the panel with `aria-controls` while it's mounted. Every line below is an automated test.

### Keyboard

| Key          | Does                                                   |
| ------------ | ------------------------------------------------------ |
| Enter, Space | Opens or closes the panel. Focus stays on the trigger. |
| Tab          | Moves from the trigger into an open panel              |

Closing a panel while focus is inside it moves focus back to the trigger.
