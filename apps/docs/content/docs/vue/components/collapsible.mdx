## Installation

```bash
npm install @ui-sdk/vue @ui-sdk/core
```

To use the examples' Tailwind classes, add the [example theme](../styling-and-animation#example-theme) to your global stylesheet.

The demos also use icons from `@lucide/vue`. Install that package if you copy their source.

## Usage

Put a trigger and a panel inside `Collapsible`. The trigger reports whether the panel is open with `aria-expanded` and points to the panel with `aria-controls` while it is mounted.

<span id="anatomy" />

```vue
<script setup lang="ts">
import { Collapsible, CollapsiblePanel, CollapsibleTrigger } from "@ui-sdk/vue/collapsible"
</script>

<template>
  <Collapsible>
    <CollapsibleTrigger>Order details</CollapsibleTrigger>
    <CollapsiblePanel>2 × Linen shirt</CollapsiblePanel>
  </Collapsible>
</template>
```

The root and panel render divs, and the trigger renders a native button. You can put other content around them.

## Behavior and Options

### Opening and Closing

Enter, Space or a click toggles the panel. Focus stays on the trigger. When you close a panel while focus is inside it, focus returns to the trigger.

By default, a closed panel unmounts, so Tab skips its contents.

### Find in Page

Set `hiddenUntilFound` on the panel to keep it in the DOM as `hidden="until-found"`. Browser Find and links to content inside the panel can reveal it. The panel opens without an animation so the match is visible immediately.

Vue renders `hidden="until-found"` on the server, so the panel can be found before hydration.

<ComponentExample
  name="collapsible/find-in-page"
  caption="Leave Ingredients closed. Open your browser's Find command and search for cardamom to reveal the panel."
/>

### Keep Mounted

Panels unmount when they close. Set `keepMounted` on the panel to keep it mounted and hidden, so a field keeps what you typed into it.

<ComponentExample
  name="collapsible/keep-mounted"
  caption="Open Add a delivery note, type a note, then close and reopen the panel. Your note is still there."
/>

### Animation

Animate the measured `--collapsible-panel-height` between zero and the content's height. `data-starting-style` marks the opening frame; `data-ending-style` stays present during the closing animation.

```vue
<CollapsiblePanel
  class="h-(--collapsible-panel-height) overflow-hidden transition-[height] duration-200 data-starting-style:h-0 data-ending-style:h-0 motion-reduce:transition-none"
/>
```

The panel stays mounted until its closing animation finishes. A panel open on its first paint does not animate. Keyframe animations can use `data-open` and `data-closed` too; respect reduced motion in either case.

`@open-change-complete` reports when opening or closing has finished.

<ComponentExample
  name="collapsible/animation"
  caption="Open and close Release notes. The status updates after the height and opacity transitions finish."
/>

### Controlled

Use `v-model:open` to keep the open state in a ref. `@open-change` also receives the change details. Call `details.cancel()` in the callback to cancel the change.

For a button elsewhere on the page, create a [controller](#controller) with `createCollapsibleController` from `@ui-sdk/vue/collapsible` and pass it as `controller`. Create one controller per mounted collapsible.

<ComponentExample
  name="collapsible/controlled"
  caption="Open Recovery codes with either button, then choose Done. The status shows the change reason, and Done returns focus to the trigger."
/>

See [State and Events](../state-and-events) for controlled state, cancellation and debugging.

## API Reference

Props are the same as below. `onOpenChange` is `v-model:open`, or `@open-change` for the details, and
`onOpenChangeComplete` is `@open-change-complete`.

### Events

Events get the new state first, then the details. `v-model` only updates when `@open-change` wasn't canceled.

| Binding                 | On            | Receives                                                     |
| ----------------------- | ------------- | ------------------------------------------------------------ |
| `v-model:open`          | `Collapsible` | Whether the panel is open                                    |
| `@open-change`          | `Collapsible` | `(open, details)`: the new state, and the [reason](#reasons) |
| `@open-change-complete` | `Collapsible` | `(open)`, after the panel's animation                        |
