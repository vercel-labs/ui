ui-sdk is a library of behaviors, like a popup, a list you move through with the arrow keys, or dragging to sort. Your agent puts them together to build the components your app needs, in Vue.

## Set Up

Copy this prompt into your agent:

```text prompt
Set up ui-sdk in this Vue project. It needs Vue 3.5 or newer.

1. Install @ui-sdk/vue and @ui-sdk/core with the project's package manager.
2. Add a note to AGENTS.md, creating it if needed: before using ui-sdk, read node_modules/@ui-sdk/vue/docs/llms.txt. To build a new component, read docs/core.md and docs/rendering.md in the same folder.
3. If you support skills, run: npx skills add vercel-labs/ui --skill ui-sdk-create-component
```

It installs ui-sdk and points your `AGENTS.md` at the docs that ship with the packages.

## Build Something

Then ask your agent to build a component:

```text prompt
Build an emoji picker with ui-sdk: a search field above a grid of emoji. Typing filters the grid, the arrow keys move between emoji, and Enter picks one. Use our existing styles.
```

Here's an emoji picker an agent built from ui-sdk's behaviors:

<ComponentExample
  name="core/emoji-picker"
  hideCode
  caption="Click an emoji to pick it, or type to search. Press Down to enter the results, use the arrow keys to move, and press Enter to pick."
/>

It uses four behaviors:

- **One Tab stop.** [`createRovingFocus`](/docs/behaviors/focus#roving-focus) lets Tab enter the grid once. The arrow keys move between emoji, and the next Tab leaves it.
- **Arrows that follow the layout.** [`spatialMove`](/docs/behaviors/focus#spatial-focus) chooses the nearest emoji in the direction you press. Down still goes down when the grid fits fewer columns on a small screen.
- **Search results.** [`fuzzyScore`](/docs/behaviors/text#rank-what-someone-searches-for) ranks each emoji's name and keywords against what you type. "party" finds the party popper, and "ship" finds the rocket.
- **Announcements.** [`announce`](/docs/behaviors/platform#announcements) tells screen readers how many emoji match and which one you picked.

Your agent picks behaviors like these for whatever you ask it to build.
