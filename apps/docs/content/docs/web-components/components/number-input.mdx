## Installation

```bash
pnpm add @ui-sdk/web @ui-sdk/core
```

Importing the component defines its elements. Import the field too if you use it. On the server the import does nothing.

```ts
import "@ui-sdk/web/number-input"
import "@ui-sdk/web/field"
```

The examples use the [shared example theme](../styling-and-animation#example-theme). The examples use `lucide` for icons.

## Anatomy

```html
<ui-number-input default-value="1" min="0">
  <ui-number-input-group>
    <ui-number-input-decrement>
      <button aria-label="Decrease">−</button>
    </ui-number-input-decrement>
    <ui-number-input-control>
      <input aria-label="Quantity" />
    </ui-number-input-control>
    <ui-number-input-increment>
      <button aria-label="Increase">+</button>
    </ui-number-input-increment>
  </ui-number-input-group>
</ui-number-input>
```

`ui-number-input` holds the numeric value. The control and button wrappers connect to your native input and buttons. Put input styles and accessible names on those native elements.

### Buttons

The step buttons repeat while held. They stay out of the Tab order because the focused input provides the same stepping actions through its arrow keys. Give each button an accessible name.

Typing updates the numeric value when the text is valid and within bounds. Enter or blur commits it: the text is parsed, clamped, snapped to the step, and formatted. An empty input has the value `null`.

### Step and Large Step

`step` sets the usual increment. Steps are measured from `min`, or from zero when no minimum is set.

| Input                                               | Increment                                          |
| --------------------------------------------------- | -------------------------------------------------- |
| ArrowUp, ArrowDown, or a step button                | `step`, which defaults to 1.                       |
| Shift with an arrow or button; Page Up or Page Down | `large-step`, which defaults to ten steps.         |
| Alt (Option) with an arrow key                      | `small-step`, which defaults to a tenth of a step. |
| Home or End                                         | The minimum or maximum, when set.                  |

### Scrub Area

`NumberInputScrubArea` changes the value while you drag. Right and up increase it. `orientation` chooses an axis, and `pixelsPerStep` controls how far the pointer moves per step. Shift and Alt (Option) use the large and small increments.

<ComponentExample
  name="number-input/scrub"
  caption="Drag Width horizontally or Height vertically. Hold Shift for larger steps or Alt (Option) for smaller ones. Click either label without dragging to select its input text."
/>

Where pointer lock is available, the drag can continue past the edge of the screen. `NumberInputScrubAreaCursor` draws a replacement cursor while it is locked. The cursor is placed in the document body with an inline translation; center your icon with negative margins.

## Behavior and Options

### Controlled

Listen for `valuechange` to read changes, and set the element’s `value` property to update it from your app. `valuechange` reports valid changes while an interaction is in progress. `valuecommit` runs when typing is committed, a step key or button is released, or a scrub ends. Use the commit event for work that should happen after the interaction.

<ComponentExample
  name="number-input/controlled"
  caption="Edit Servings or hold a step button. Value updates as it changes; Committed updates when the interaction ends. Clear sets the value to null, and Reset to 4 restores it."
/>

See [State and Events](../state-and-events) for the shared state conventions and [Reasons](#reasons) for the events specific to Number Input.

### Controller

Use the element’s `api` for actions outside the field. It also accepts a controller created with `createNumberInputController()`. `increment()` and `decrement()` step the value; pass `{ large: true }` for a large step. `setValue()`, `getValue()`, and `focus()` cover direct updates and inspection.

<ComponentExample
  name="number-input/controller"
  caption="Try Zoom in and Zoom out, then Actual size to restore 100. Read reports the current value, and Focus moves into the field."
/>

[Controllers](../controllers) covers creating and sharing a controller.

## Forms

The root custom element is form-associated and submits the plain numeric value. Formatting does not change form data: a displayed currency amount still submits a value such as `1234.5`. Empty values submit an empty string.

<ComponentExample
  name="number-input/form"
  caption="Change Quantity or Tip and choose Save to read the plain numeric values. Gift cards belongs to the same form through its form ID. Reset restores the defaults."
/>

Set `form` to associate the input with a form elsewhere in the page. A form reset restores the default value and reports the `reset` reason.

## API Reference

Props are attributes in kebab case, like `default-value`, `large-step` and `read-only`. `format` and
`controller` are properties. Callbacks are DOM events.

### Events

Events fire on their own element and don't bubble, with the value in `event.detail.value` and the `reason` and `event` beside it. Calling `preventDefault()` on `valuechange` cancels the change.

| Member                      | On                | Description                                                           |
| --------------------------- | ----------------- | --------------------------------------------------------------------- |
| `value` property, attribute | `ui-number-input` | The value, or null when empty. An empty attribute is empty            |
| `format` property           | `ui-number-input` | `Intl.NumberFormat` options                                           |
| `api` property              | `ui-number-input` | The [controller](#controller)                                         |
| `valuechange` event         | `ui-number-input` | `detail: { value, reason, event, source }`, as the value changes      |
| `valuecommit` event         | `ui-number-input` | `detail: { value, reason, event, source }`, once the interaction ends |
