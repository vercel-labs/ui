## Installation

```bash
pnpm add @ui-sdk/web @ui-sdk/core
```

Importing the component defines its elements. Import the field too if you use it. On the server the import does nothing.

```ts
import "@ui-sdk/web/otp-input"
import "@ui-sdk/web/field"
```

The examples use the [shared example theme](../styling-and-animation#example-theme). The separator icons use `lucide`.

## Anatomy

```html
<ui-otp-input max-length="4" aria-label="Verification code">
  <ui-otp-input-group>
    <ui-otp-input-slot></ui-otp-input-slot>
    <ui-otp-input-slot></ui-otp-input-slot>
    <ui-otp-input-slot></ui-otp-input-slot>
    <ui-otp-input-slot></ui-otp-input-slot>
  </ui-otp-input-group>
</ui-otp-input>
```

`ui-otp-input` creates the native input and holds the code. A group lays out its slots. Slots without an explicit `index` follow their order in the input. Add `ui-otp-input-separator` between groups when the code is easier to read in sections.

<span id="separator" />

Groups and separators change the presentation of one value. They do not create additional fields or tab stops.

<span id="one-input-not-one-per-slot" />

### One Input

The slots display the value of a single native input. That input handles selection, paste, undo, form submission, and autofill. It uses `autocomplete="one-time-code"` so supported browsers and password managers can offer a saved or received code.

Arrow keys, Home, and End move the selection. Pasting a code such as `123-456` removes separators. The active slot gets `data-active`; an empty active slot gets `data-fake-caret` for drawing its caret.

Set `max-length` to the code's length and render that many slots. The default length is six.

### Alphanumeric

Set `pattern` to `digits`, `letters`, or `alphanumeric`. The default is `digits`. The pattern filters characters and selects a suitable keyboard on touch devices.

### Custom Pattern

Pass a regex string, such as `pattern="[0-9A-Fa-f]"` to accept hexadecimal characters. Use `input-mode` to choose the keyboard separately. The example displays letters in uppercase without changing their stored case.

### Disabled and Read-Only

A disabled input cannot be focused, changed, or submitted. `read-only` prevents changes while keeping the input focusable and included in form data.

## Behavior and Options

### Controlled

Listen for `valuechange` to read changes and set the element’s `value` property to update it from your app. Call `event.preventDefault()` in the change listener to reject a change. Incoming values are filtered by the pattern and limited to `max-length`, just like typed values.

<ComponentExample
  name="otp-input/controlled"
  caption="Enter or edit the one-time password. The text below follows the current code."
/>

See [State and Events](../state-and-events) for the shared state conventions. The [reason](#reasons) distinguishes typing, pasting, undo, and controller actions.

### On Complete

The `valuecommit` event runs when a change fills every slot, including typing, paste, autofill, and controller writes. Changing an already-full code runs it again. Form resets and page restoration do not.

<ComponentExample
  name="otp-input/complete"
  caption="Fill all six slots. The status shows the complete code and the change reason. Replace a digit to trigger it again, or delete a digit to clear the status."
/>

### Controller

Use the element’s `api` to read, fill, clear, or focus it. It also accepts a controller created with `createOTPInputController()`. Writes use the `imperative` reason and pass through the same filtering and change callbacks as typing.

<ComponentExample
  name="otp-input/controller"
  caption="Choose Fill to enter 123456, Read to inspect the value, Clear to empty it, and Focus to move into the input."
/>

[Controllers](../controllers) covers creating and sharing a controller.

## Forms

Set `name` to include the code in `FormData`. `required` blocks an empty code, and a partial code fails length validation. Reset restores the default value. Use `form` to associate a control outside the form with its ID.

<ComponentExample
  name="otp-input/form"
  caption="Choose Verify with an empty or partial code to see validation. Enter all six digits and submit to read the form values. The optional recovery code belongs to the same form. Reset restores both fields."
/>

A typed partial code reports `tooShort`. Partial default values and controller writes are checked through the native input's pattern, because browsers do not apply minlength validation to those values.

## Styling

Draw the active slot and caret with `data-active` and `data-fake-caret`. The examples include the caret animation and disable it for reduced motion. Keep `position: relative` on each slot so its caret stays inside it.

## API Reference

Props are attributes in kebab case, like `max-length`, `default-value` and `auto-complete`. `pattern` is a
preset name or the source of a regular expression. `controller` is a property. Callbacks are DOM events.

### Events

Events fire on their own element and don't bubble, with the code in `event.detail.value` and the `reason` and `event` beside it. Calling `preventDefault()` on `valuechange` cancels the change.

| Member                      | On             | Description                                                |
| --------------------------- | -------------- | ---------------------------------------------------------- |
| `value` property, attribute | `ui-otp-input` | The code                                                   |
| `api` property              | `ui-otp-input` | The [controller](#controller)                              |
| `valuechange` event         | `ui-otp-input` | `detail: { value, reason, event }`, on every change        |
| `valuecommit` event         | `ui-otp-input` | `detail: { value, reason, event }`, when a change fills it |

### Reasons

`event.detail.reason` says why the code changed. Autofill and a code from the keyboard's suggestions are `input-change`.

## Accessibility

Name the input with FieldLabel, a native label, `aria-label`, or `aria-labelledby`. Screen readers encounter one input with the whole code; the visual slots, groups, and separators are hidden from them.
