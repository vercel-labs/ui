## Installation

```bash
npm install @ui-sdk/web @ui-sdk/core
```

Importing the component defines its elements. On the server the import does nothing.

```ts
import "@ui-sdk/web/pagination"
```

The examples use the shared [Example Theme](../styling-and-animation#example-theme).

## Anatomy

Name the navigation with `aria-label`, then put the page links and steps in a list.

```html
<ui-pagination aria-label="Pagination" page-count="10">
  <ui-pagination-list>
    <ui-pagination-item>
      <ui-pagination-previous><button>Previous</button></ui-pagination-previous>
    </ui-pagination-item>
    <template>
      <ui-pagination-item>
        <ui-pagination-link><button></button></ui-pagination-link>
      </ui-pagination-item>
    </template>
    <template data-ellipsis>
      <ui-pagination-item>
        <ui-pagination-ellipsis>…</ui-pagination-ellipsis>
      </ui-pagination-item>
    </template>
    <ui-pagination-item>
      <ui-pagination-next><button>Next</button></ui-pagination-next>
    </ui-pagination-item>
  </ui-pagination-list>
</ui-pagination>
```

A list with a `<template>` renders the range from it: one copy for each page, with the page number in an empty button, and the `<template data-ellipsis>` for each gap. Without the ellipsis template, gaps get a plain `<ui-pagination-ellipsis>`. Links and steps wrap your own `<button>`, or an `<a>` with [`getHref`](#links), so style those. Links written out by hand, like a server's, take a `page` attribute.

The template keeps page entries keyed as the range moves. The current page's wrapped button gets `aria-current="page"` and `data-active`; an ellipsis is hidden from screen readers.

Give each step text or an `aria-label` on its wrapped button. At an end, the button gets `aria-disabled="true"` and `data-disabled` and stops changing the page, while staying in the tab order.

### Links

Set the `getHref` property, a function from a page to its URL, and wrap `<a>` elements instead of buttons.

Server-rendered anchors work before JavaScript loads. A normal click changes the page and follows the URL. Modifier clicks and middle clicks leave pagination state alone so the browser can open the link elsewhere.

A step at its end loses its `href` and leaves the tab order, but keeps focus if it already had it. During navigation, its original `href` stays in place so Next cannot accidentally follow the next page's URL.

### Router Links

Render your router's link to page on the client. The pagination's click handler runs first: when a change is canceled or a step is at its end, it calls `preventDefault()`, and the router leaves the link alone.

Parts bind whatever `<a>` they wrap, so a router that listens for clicks on links keeps working. Check
`event.defaultPrevented` before navigating. The element owns its page, so the route follows the
pagination here.

### Right to Left

Set `dir="rtl"` on the page or any element around the pagination. The list runs from the right, so Previous sits on the right and Next on the left. Turn directional icons with `rtl:rotate-180`.

## Behavior and Options

### Controlled

The element owns its page. Listen for `pagechange`, and call `preventDefault()` on it to keep the current
page. The `page` property reads the page, and setting it goes there.

Every change carries a [reason](#reasons): `item-press` for a page, `previous-press`, `next-press`, `first-press` or `last-press` for a step, and `imperative` from a [controller](#controller). A canceled change, like one while a form has unsaved changes, also stops a link from navigating.

### Default Page

`default-page` is the page it starts on, when uncontrolled. It's 1 by default.

<ComponentExample name="pagination/default-page" caption="Start on page 5, then choose another page." />

### Siblings

`siblings` is how many pages show on each side of the current one, 1 by default. Near an end, the window slides over instead of shrinking, keeping the range length stable. A gap of one page shows that page instead of an ellipsis.

<ComponentExample
  name="pagination/siblings"

/>

### Boundaries

`boundaries` is how many pages always show at each end, 1 by default.

### Total and Page Size

Instead of `page-count`, pass `total`, how many items there are, and `page-size`, how many fit on a page (10
by default). Pagination calculates the page count, with a minimum of one. This example resets to page 1 when the page size changes.

A page past the end, like after the count shrinks, reads as the last page.

## Focus

Steps rendered as buttons stay focusable at the ends. A clicked page link keeps focus as the range moves; the primitive also tries to restore focus to that page or step if rendering replaces its element. Key range entries by their value rather than their index.

## Styling

Parts are unstyled. Style them through the attributes they render, which are the same in every framework: `aria-current="page"` or `data-active` on the current page's link, and `aria-disabled` or `data-disabled` on a step at its end.

```html
<ui-pagination-link>
  <button class="aria-[current=page]:border data-active:font-medium"></button>
</ui-pagination-link>
<ui-pagination-next>
  <button class="aria-disabled:opacity-50">Next</button>
</ui-pagination-next>
```

The list and its items are `<ui-pagination-list>` and `<ui-pagination-item>`, which display as blocks. Give the list `flex` to lay the pages out in a row.

## API Reference

Props are attributes in kebab case, like `page-count`, `default-page` and `page-size`, and numbers are
numbers. `getHref` and `controller` are properties. `page` is a live property. Callbacks are DOM events.

### Events

Events fire on their own element and don't bubble, with the new page in `event.detail.value` and the `reason` and `event` beside it. Calling `preventDefault()` cancels the change. Type the element as `UiPaginationElement` for typed listeners.

| Member                | On              | Description                                          |
| --------------------- | --------------- | ---------------------------------------------------- |
| `page` property       | `ui-pagination` | The current page. Setting it goes there              |
| `api` property        | `ui-pagination` | The [controller](#controller)                        |
| `getHref` property    | `ui-pagination` | A page's URL. With it, wrap links instead of buttons |
| `controller` property | `ui-pagination` | A controller from `createPaginationController()`     |
| `pagechange` event    | `ui-pagination` | `detail: { value: page, reason, event, source }`     |
