Use Tabs when several views share the same space, such as settings sections or a preview and its source. Each tab opens the panel with the same value.

## Installation

```bash
npm install @ui-sdk/web @ui-sdk/core
```

Import the element definitions once in your application:

```ts
import "@ui-sdk/web/tabs"
```

To use the examples’ Tailwind classes, add the [example theme](../styling-and-animation#example-theme) to your global stylesheet.

The icon example uses `lucide`. Install it to copy that example as shown, or use your own icons.

```bash
npm install lucide
```

## Anatomy

Give each tab and its panel the same unique `value`. Give the list an accessible name. Put a native button inside each `ui-tabs-tab`. Set `default-value` to choose the initial tab; otherwise, the first enabled tab is selected.

```html
<ui-tabs default-value="account">
  <ui-tabs-list aria-label="Settings">
    <ui-tabs-tab value="account"><button type="button">Account</button></ui-tabs-tab>
    <ui-tabs-tab value="password"><button type="button">Password</button></ui-tabs-tab>
  </ui-tabs-list>
  <ui-tabs-panel value="account">Manage your profile.</ui-tabs-panel>
  <ui-tabs-panel value="password" hidden>Choose a new password.</ui-tabs-panel>
</ui-tabs>
```

Tab enters the list at the selected tab. Left and Right Arrow move between tabs and select them. Home and End move to the first and last tabs.

<span id="right-to-left" />

The list reads `dir="rtl"` from the page or any ancestor. Arrow directions follow the reading direction, with no provider.

### Manual Activation

Set `activation="manual"` when opening a panel takes time, such as a view that fetches data. Arrow keys move focus; Enter or Space selects the focused tab.

```html
<ui-tabs activation="manual"></ui-tabs>
```

A panel becomes a tab stop only when it has no focusable content. A panel with a field lets Tab go straight to the field.

### Indicator

`ui-tabs-indicator` measures the selected tab. Position it inside a relative tab list and use its CSS variables to make a marker that follows the selection. It measures again when a tab or the list changes size.

```html

  class="absolute top-(--active-tab-top) left-(--active-tab-left) h-(--active-tab-height) w-(--active-tab-width)"
></ui-tabs-indicator>
```

### Find in Page

Add `hidden-until-found` to the tabs or a panel to keep closed content available to the browser’s Find command. A match selects its tab with the reason `find-in-page`. This also keeps the panel mounted.

Write `hidden="until-found"` on the initially hidden panels too if they should be findable before the elements are defined.

### Animation

Panels expose `data-starting-style` as they enter and `data-ending-style` as they leave. The previous panel stays mounted through its exit animation, then unmounts or hides if it is kept mounted.

Use `data-activation-direction` to choose a slide direction. Put both panels in the same grid cell so they overlap during the transition, as this example does.

### Controlled

Read and set the element’s `value` property, or call its `api.select(value)` method. Setting the property or attribute fires no event; the `api` and the person choosing a tab do. [State and Events](../state-and-events) covers the shared pattern. Call `event.preventDefault()` on `valuechange` to reject a change.

`valuechange` receives the new value and a [reason](#reasons), such as `item-press`, `list-navigation`, or `imperative`. It does not run for the initial selection. Use the element’s `api` to select a tab from another control.

<ComponentExample
  name="tabs/controlled"
  caption="Choose Drafts, then press Show sent mail. The selected value and the reason for each change appear below."
/>

### Links

Render a tab as a link when selection should navigate. It keeps its tab role; arrow keys follow the link when they select it. Modified clicks, such as Cmd-click, keep their normal browser behavior without selecting the tab.

```html
<ui-tabs-tab value="activity">
  <a href="#activity">Activity</a>
</ui-tabs-tab>
```

## Patterns

### Sync with the URL

Use the URL as the source of the selected value, and validate it against your tab values. The approach depends on what the URL represents.

#### Query Parameter

Read the parameter on the server when possible, then pass it as the controlled value. Write changes through your router so browser navigation and the rendered page stay in sync. For a plain client page, preserve the rest of the URL when updating it:

```ts
function saveSelectedTab(value: string | null) {
  const url = new URL(location.href)
  if (value === null) {
    url.searchParams.delete("tab")
  } else {
    url.searchParams.set("tab", value)
  }
  history.replaceState(null, "", url)
}
```

Call this from `valuechange` after accepting the value. Read it again on `popstate` if your page uses browser history directly; remove that listener when the view unmounts.

#### Hash

A hash such as `#activity` works on a client-rendered page. Read it after mount and on `hashchange`, then select the matching tab. Setting `location.hash` adds a history entry. The server cannot read the hash, so give the page an initial tab while it loads.

#### Route Tabs

When each tab is a route, render links and derive the controlled value from the current path. Let navigation update the value. You do not also need a change handler that navigates to the same route.

<span id="web-components" />

Set the element’s `value` attribute when the URL changes. If the server renders the markup, set its initial `value` and hide the other panels there too.

### Scrolling the Selected Tab into View

If the list scrolls, selecting a tab through a controller or the URL scrolls it into view inside that list. Pointer and arrow-key selection focus the tab, so the browser reveals it as part of focusing it.

## API Reference

Props are attributes in kebab case, like `default-value`, `keep-mounted` and `hidden-until-found`: `"false"`
is false. Callbacks are DOM events.

### Events

Events fire on their own element and don't bubble, with the new value in `event.detail.value` and the `reason` and `event` beside it. Calling `preventDefault()` on `valuechange` keeps the current tab.

| Member                      | On        | Description                                    |
| --------------------------- | --------- | ---------------------------------------------- |
| `value` property, attribute | `ui-tabs` | The selected tab. Setting either selects a tab |
| `api` property              | `ui-tabs` | The [controller](#controller)                  |
| `valuechange` event         | `ui-tabs` | `detail: { value, reason, event, source }`     |
