ui-sdk is a library of behaviors, like a popup, a list you move through with the arrow keys, or dragging to sort. Your agent puts them together to build the components your app needs, in React.

## Set Up

Copy this prompt into your agent:

```text prompt
Set up ui-sdk in this React project. It needs React 19 or newer.

1. Install @ui-sdk/react and @ui-sdk/core with the project's package manager.
2. Add a note to AGENTS.md, creating it if needed: before using ui-sdk, read node_modules/@ui-sdk/react/docs/llms.txt. To build a new component, read docs/core.md and docs/rendering.md in the same folder.
3. If you support skills, run: npx skills add vercel-labs/ui --skill ui-sdk-create-component
```

It installs ui-sdk and points your `AGENTS.md` at the docs that ship with the packages.

## Build Something

Then ask your agent to build a component:

```text prompt
Build an icon picker with ui-sdk: a button that opens a popover with a search field above a grid of icons. Typing filters the grid, the arrow keys move between icons, and Enter picks one. Use our existing styles.
```

Here's an icon picker an agent built from ui-sdk's behaviors:

<ComponentExample
  name="core/icon-picker"
  caption="Click Pick an icon to open the picker, then click an icon or type to search. The best match is highlighted, so Enter picks it. Press Down to enter the results and use the arrow keys to move."
/>

It uses five behaviors:

- **A popover.** [`createPopup`](/docs/behaviors/popups#a-popup-of-your-own) with the popover preset opens the picker beside its button, moves focus to the search field, and closes on Escape or a click outside. Picking an icon closes it and puts focus back on the button.
- **One Tab stop.** [`createRovingFocus`](/docs/behaviors/focus#roving-focus) lets Tab enter the grid once. The arrow keys move between icons, and the next Tab leaves it.
- **Arrows that follow the layout.** [`spatialMove`](/docs/behaviors/focus#spatial-focus) chooses the nearest icon in the direction you press. Down still goes down when the grid fits fewer columns on a small screen.
- **Search results.** [`fuzzyScore`](/docs/behaviors/text#rank-what-someone-searches-for) ranks each icon's name and keywords against what you type. "idea" finds the lightbulb, and "launch" finds the rocket.
- **Announcements.** [`announce`](/docs/behaviors/platform#announcements) tells screen readers how many icons match what you type.

Your agent picks behaviors like these for whatever you ask it to build.
