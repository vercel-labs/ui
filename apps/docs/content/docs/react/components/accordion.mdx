Use an Accordion for content people can explore one section at a time, such as answers, settings, or a course outline. Each heading is a button that opens its panel.

## Installation

```bash
npm install @ui-sdk/react @ui-sdk/core
```

To use the examples' Tailwind classes, add the [example theme](../styling-and-animation#example-theme) to your global stylesheet.

The examples use `lucide-react` for icons. Install it to copy the examples as shown, or use your own icons.

```bash
npm install lucide-react
```

## Anatomy

Give every item a unique `value`. Put its trigger inside a heading, then add the panel it opens. The accordion's value is always an array of open item values, even when only one can be open.

```tsx
import {
  Accordion,
  AccordionHeader,
  AccordionItem,
  AccordionPanel,
  AccordionTrigger,
} from "@ui-sdk/react/accordion"

function Example() {
  return (
    <Accordion>
      <AccordionItem value="shipping">
        <AccordionHeader>
          <AccordionTrigger>Shipping</AccordionTrigger>
        </AccordionHeader>
        <AccordionPanel>Orders arrive in five to seven days.</AccordionPanel>
      </AccordionItem>
    </Accordion>
  )
}

export { Example }
```

`AccordionHeader` renders an `h3` by default. Use a heading level that fits the surrounding document. Tab moves between triggers; Enter or Space opens and closes their panels.

### Collapsible

Set `collapsible={false}` when the open item should stay open until another item replaces it. This does not choose an initial item: set `defaultValue={["overview"]}` too if a panel should start open.

The open trigger reports `aria-disabled="true"` because pressing it cannot close its panel.

```tsx
<Accordion collapsible={false} defaultValue={["overview"]} />
```

### Animation

The panel exposes its measured height as `--accordion-panel-height`. Animate that height to or from zero with `data-starting-style` and `data-ending-style`:

```tsx
<AccordionPanel className="h-(--accordion-panel-height) overflow-hidden transition-[height] data-starting-style:h-0 data-ending-style:h-0" />
```

The panel stays mounted until its exit animation finishes. An item's `onOpenChangeComplete` runs afterward with the open state. Initially open panels show immediately; they do not animate or call the completion callback on mount.

<ComponentExample
  name="accordion/animation"
  caption="Open or close an item. The message below updates after the panel finishes its height animation."
/>

### Controlled

Use `value` and `onValueChange` to own the open items. [State and Events](../state-and-events) covers the shared pattern.

An item can refuse a change: call `details.cancel()` in its `onOpenChange` callback. Item callbacks run before the accordion's `onValueChange`, including the item that would close when another opens. Canceling any one of them cancels the whole change.

<ComponentExample
  name="accordion/controlled"
  caption="Press Expand all, then Collapse all. Cancel the confirmation to keep Security open; accept it to close the section."

### Open the Item in the URL Hash

A hash can name an item's `value` instead of an element inside its panel. Read it after mount and on `hashchange`, then open and focus the matching item through your controller:

```ts
const value = decodeURIComponent(location.hash.slice(1))
if (items.some((item) => item.value === value)) {
  accordion.open(value)
  accordion.focus(value)
}
```

Check the value against your items first. A controller can hold a value even when no item renders it. Remove the `hashchange` listener when the component unmounts.

### Keep Open Items in the Query String

Use `open` query parameters when several items should be shareable. Read the initial values from your router on the server, then write accepted changes back to the URL:

```ts
function saveOpenItems(value: string[]) {
  const url = new URL(location.href)
  url.searchParams.delete("open")
  for (const item of value) url.searchParams.append("open", item)
  history.replaceState(null, "", url)
}
```

Call this from `onValueChange` after updating your state. If your app already has a router, use its navigation API instead.

### Scroll an Item into View

Scroll after `onOpenChangeComplete`, when the panel has its full height. Scrolling in `onOpenChange` would measure it before it opens. The [Expand All example](#expand-all) shows the full setup and scrolls only when someone opens a single item.

## API Reference

Props and callbacks are the same as below, as React props. Headers, triggers and panels take their item's
value from the item.

### Events

Callbacks get the new state first, then the details.

| Prop                   | On              | Receives                                                       |
| ---------------------- | --------------- | -------------------------------------------------------------- |
| `onValueChange`        | `Accordion`     | `(value, details)`: the open items, and the [reason](#reasons) |
| `onOpenChange`         | `AccordionItem` | `(open, details)`, before `onValueChange`                      |
| `onOpenChangeComplete` | `AccordionItem` | `(open)`, after the panel's animation                          |
