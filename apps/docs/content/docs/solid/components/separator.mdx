## Installation

```bash
pnpm add @ui-sdk/solid @ui-sdk/core
```

## Usage

A separator marks a boundary between groups of content. Give it a size and a background:

```tsx
import { Separator } from "@ui-sdk/solid/separator"

function Account() {
  return (
    <section>
      <h2>Account</h2>
      <Separator class="h-px bg-neutral-200" />
      <p>Manage your profile and preferences.</p>
    </section>
  )
}

export { Account }
```

<span id="composition" />

It renders with `role="separator"` and `aria-orientation="horizontal"` by default. It does not receive focus or resize the content around it.

## Examples

### Vertical

Set `orientation="vertical"` for a line between items in a row. Give the row a height and let the separator stretch to fill it.

### Decorative

Set `decorative` when the line adds no information. Here, the word “or” already describes the division, so a screen reader skips the lines.

<ComponentExample
  name="separator/decorative"
  caption="Read through “or” with a screen reader. The decorative lines are skipped."
/>

A decorative separator gets `role="none"` and no `aria-orientation`. It still has `data-orientation` for styling.

## Styling

Use `data-orientation` to give horizontal lines a height and vertical lines a width. The Code tab shows both approaches in full.

## Accessibility

The component follows the [WAI-ARIA separator role](https://www.w3.org/TR/wai-aria-1.2/#separator). It is a static separator, so Tab moves past it. Use `decorative` only when the surrounding content already conveys the division.
