Use a Time Input for a time of day, like a meeting or an opening hour. It works like [Date Input](./date-input), with segments for the hour, the minute and, on a 12-hour clock, AM or PM.

<ComponentExample
  name="date-input/time"
  caption="Click the hour and type 230, then P. Press ArrowUp or ArrowDown on a part to step it."
/>

## Installation

```bash
npm install @ui-sdk/solid @ui-sdk/core
```

## Composition

Use the following composition to build a `TimeInput`:

```text
TimeInput
├── TimeInputSegment
└── TimeInputSegment
```

`TimeInput` renders a group with one `TimeInputSegment` for each part of the time, and the text between them.

## Usage

Put the input in a [Field](./field) and give it a label:

```tsx
import { Field, FieldLabel } from "@ui-sdk/solid/field"
import { TimeInput } from "@ui-sdk/solid/time-input"

function Example() {
  return (
    <Field>
      <FieldLabel>Meeting time</FieldLabel>
      <TimeInput defaultValue="09:30" />
    </Field>
  )
}

export { Example }
```

The value is a 24-hour time like `"14:30"`, the same as a native time input's, whatever clock the input shows. Typing, stepping and pasting work as they do in [Date Input](./date-input#usage).

## Clock and Seconds

The input shows the locale's clock. Set `hourCycle` to `12` or `24` to choose one, and `granularity` to `"second"` to add seconds, or `"hour"` to show the hour alone.

## Min and Max

`min` and `max` take times like `"09:00"`. A time outside them is invalid: the input sets `data-invalid`, and its form won't submit.

## Form

A hidden input submits the time under `name`. Set `required` to need a time before the form submits, and `form` to the id of a form elsewhere in the page to submit with it. The [Date Input form example](./date-input#form) has a time in it.

## Controlled and Controller

Pass `value` and update it in `onValueChange`, or drive the input with `createTimeInputController()`, as in [Date Input](./date-input#controlled).

## Styling

Style it like [Date Input](./date-input#styling). The AM/PM segment sets `data-type="dayPeriod"`.

Each part has a `data-slot`, such as `time-input-segment`, and its state attributes are listed under [Data Attributes](#data-attributes).

| Prop            | On          | Receives                                                                           |
| --------------- | ----------- | ---------------------------------------------------------------------------------- |
| `onValueChange` | `TimeInput` | `(value, details)`: the time, or null once it's erased, and the [reason](#reasons) |

## Accessibility

The root is a group, named by its Field's label or by your `aria-label`. Each segment is a spinbutton named by its unit, like "hour" or "AM/PM", with its value, range and text. The keys are the same as in [Date Input](./date-input#keyboard).
