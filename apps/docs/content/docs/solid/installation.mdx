---

Start with an app using Solid 2. Both `solid-js` and `@solidjs/web` must be version `2.0.0-rc.14` or newer, below version 3. Solid 1 isn't supported.

For a new app, run Solid's starter and choose Solid 2.0 as the project type:

```bash
npm init solid@latest
```

## Install the Packages

```bash
npm install @ui-sdk/solid @ui-sdk/core
```

`@ui-sdk/solid` provides the Solid components. `@ui-sdk/core` provides their behavior and is a peer dependency. Install both so the components and any helpers you use share one copy of the core.

With Vite, leave `@ui-sdk/core` out of dependency pre-bundling. Otherwise a core entry your app imports, like `@ui-sdk/core/tabs`, is bundled apart from the copy `@ui-sdk/solid` loads, and `@ui-sdk/solid`'s components throw in development. Add `optimizeDeps` to the starter's config:

```ts title="vite.config.ts"
import solid from "@solidjs/vite-plugin"
import { defineConfig } from "vite"

export default defineConfig({
  plugins: [solid({ start: true })],
  optimizeDeps: { exclude: ["@ui-sdk/core"] },
})
```

## Import a Component

Import each component from its own entry:

```tsx
import { Button } from "@ui-sdk/solid/button"
import { Toggle } from "@ui-sdk/solid/toggle"
```

A Dialog has separate parts for its trigger, content, and title. Import those parts from the same entry:

```tsx
import {
  Dialog,
  DialogContent,
  DialogTitle,
  DialogTrigger,
} from "@ui-sdk/solid/dialog"
```

Each [component page](./components) lists the parts you can use.

## Add Your Styles

Components are unstyled, so you style them with your app's CSS or with Tailwind CSS. [Styling and Animation](./styling-and-animation) covers both.

For a default look to start from, import `@ui-sdk/core/web.css` once, at the top of your app's entry, like `src/App.tsx` in an app from the starter:

```ts
import "@ui-sdk/core/web.css"
```

With Tailwind CSS, import it in your global stylesheet instead, after Tailwind. `layer(components)` puts it above Tailwind's base styles, so they don't reset it, and below its utilities, so a class still wins. Declare [the ui-sdk layer](./styling-and-animation#the-ui-sdk-layer) above both:

```css
@layer ui-sdk;

@import "tailwindcss";
@import "@ui-sdk/core/web.css" layer(components);
```

You can render your first component without setting up a provider or adding a portal root. [Server Rendering](./server-rendering) covers rendering initial HTML and hydrating it in the browser.

Continue with [First Component](./first-component) to add a working toggle to your app.
