---

Start with an app using Solid 2. Both `solid-js` and `@solidjs/web` must be version `2.0.0-rc.14` or newer, below version 3. Solid 1 isn't supported.

## Install the Packages

```bash
npm install @ui-sdk/solid @ui-sdk/core
```

`@ui-sdk/solid` provides the Solid components. `@ui-sdk/core` provides their behavior and is a peer dependency. Install both so the components and any helpers you use share one copy of the core.

With Vite, use Solid 2's plugin, `@solidjs/vite-plugin`, in place of `vite-plugin-solid`, which only supports Solid 1. Also leave `@ui-sdk/core` out of Vite's dependency pre-bundling. Otherwise a core entry your app imports, like `@ui-sdk/core/tabs`, is bundled apart from the copy `@ui-sdk/solid` loads, and `@ui-sdk/solid`'s components throw in development:

```ts title="vite.config.ts"
import solid from "@solidjs/vite-plugin"
import { defineConfig } from "vite"

export default defineConfig({
  plugins: [solid()],
  optimizeDeps: { exclude: ["@ui-sdk/core"] },
})
```

The Vite template starts on Solid 1. Move it to Solid 2 and swap the plugin:

```bash
npm uninstall vite-plugin-solid
npm install solid-js@next @solidjs/web@next
npm install -D @solidjs/vite-plugin
```

Then import `render` from `@solidjs/web` instead of `solid-js/web` in `src/index.tsx`, and set `"jsxImportSource": "@solidjs/web"` in `tsconfig.app.json`.

## Import a Component

Import each component from its own entry:

```tsx
import { Button } from "@ui-sdk/solid/button"
import { Toggle } from "@ui-sdk/solid/toggle"
```

A Dialog has separate parts for its trigger, content, and title. Import those parts from the same entry:

```tsx
import {
  Dialog,
  DialogContent,
  DialogTitle,
  DialogTrigger,
} from "@ui-sdk/solid/dialog"
```

Each [component page](./components) lists the parts you can use.

## Add Your Styles

Components are unstyled, so you style them with your app's CSS or with Tailwind CSS. [Styling and Animation](./styling-and-animation) covers both.

You can render your first component without setting up a provider, importing a UI SDK stylesheet, or adding a portal root. [Server Rendering](./server-rendering) covers rendering initial HTML and hydrating it in the browser.

Continue with [First Component](./first-component) to add a working toggle to your app.
